# 구글, 맥용 제미나이 앱에 '컴퓨터 사용' 기능 추가…앱·파일·웹 넘나들며 여러 단계 작업 대행

## 상세 요약

구글이 11월 19일(현지시간) macOS용 제미나이 데스크톱 앱에 '컴퓨터 사용(computer use)' 기능을 넣는다고 발표했다. 제미나이가 맥의 기본 앱을 조작하고 백그라운드에서 웹사이트를 탐색하며 사용자 대신 작업을 처리하는 AI 에이전트 기능이다.

로컬 파일과 데스크톱 앱, 웹을 오가며 여러 단계로 이뤄진 작업을 처리할 수 있다. 구글은 활용 예로 양식 작성, 여러 파일에 같은 작업 반복하기, 특정 기준에 따라 파일을 폴더로 정리하기, 파일이나 온라인 대시보드 정보로 슬라이드 만들기를 들었다.

사용자가 지시를 내리면 에이전트는 채팅 창 안의 실시간 미리보기에서 작업한다. 그동안 사용자의 화면과 커서는 그대로 비어 있어 다른 일을 할 수 있다. 테크크런치에 따르면 사용자는 제미나이의 행동을 실행 전에 일시 정지·중단·승인할 수 있으며, 이는 컴퓨터 사용 기능을 갖춘 다른 AI 에이전트와 같은 방식이다.

우선 미국에서 영어로만 제공되며, 맥용 제미나이 앱과 구글 AI 플러스·프로·울트라 구독이 필요하다. 다른 지역이나 플랫폼으로의 확대 시점은 밝히지 않았다.

테크크런치는 오픈AI·앤트로픽·메타가 이미 데스크톱 앱에서 에이전트 기능을 제공하고 있어 구글이 뒤늦게 합류한 것이라고 평가했다. 구글은 지난주 웹사이트 로그인과 결제, 예약까지 대신하는 제미나이 '태스크'의 확대도 발표한 바 있다.

## 핵심 포인트

- 맥용 제미나이가 기본 앱 조작과 백그라운드 웹 탐색으로 작업을 대신한다.
- 파일 정리, 양식 작성, 슬라이드 생성 같은 여러 단계 작업을 지원한다.
- 실행 전 일시 정지·중단·승인이 가능하고, 작업 중에도 사용자는 화면을 쓸 수 있다.
- 미국·영어로 먼저 출시되며 AI 플러스·프로·울트라 구독자가 대상이다.
