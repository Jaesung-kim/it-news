# PHP 8.6 정식 출시…같은 날 '치명' 등급 포함 보안 릴리스 8.5.13·8.4.28·8.3.37·8.2.36 배포

- 출처: PHP 공식 사이트(php.net), GeekNews
- 원문: https://www.php.net/releases/8.6/en.php
- 공식 출처: https://www.php.net/archive/2026.php#2026-11-18-1 , https://www.php.net/ChangeLog-8.php#8.6.0
- 발행일: 2026-11-19

## 상세 요약

PHP 개발팀이 11월 19일 새 마이너 버전 PHP 8.6.0을 정식 출시했다. 같은 날 지원 중인 기존 버전용 보안 릴리스 PHP 8.5.13, 8.4.28, 8.3.37, 8.2.36도 함께 내놨다. 각 버전 공지에는 "보안 릴리스"라고 명시돼 있다.

보안 릴리스는 하루 전 미리 예고됐다. PHP 보안팀은 11월 18일 공지에서 지원 중인 모든 버전에 영향을 주는 취약점을 고친다며 배포 시각을 19일 14:00~14:30(UTC)으로 안내했다. 공지는 최고 심각도를 "CRITICAL"로 밝혔고, 이 등급의 문제는 기본값이 아닌 설정이나 흔치 않은 구성에서만 발생한다고 덧붙였다. 배포 즉시 업그레이드할 수 있도록 준비하라는 권고도 담겼다.

공식 변경 이력(ChangeLog)의 8.6.0 항목에는 GitHub 보안 권고(GHSA)와 CVE 번호가 붙은 수정 사항이 여럿 올라 있다. 매직 메서드 백트레이스의 해제 후 사용(CVE-2026-129474), 시간대 캐시 해제 후 사용(CVE-2026-129496), 일부만 덮어쓴 세션 파일(CVE-2026-126714)은 원격 코드 실행으로 이어질 수 있는 문제로 기재됐다. PHP-FPM에서는 epoll 해제 후 사용에 따른 로컬 권한 상승(CVE-2026-129291), 읽지 않은 요청 본문을 통한 요청 스머글링(CVE-2026-129289), 상태 페이지 XSS(CVE-2026-129292)가 고쳐졌다. PHAR 서명 검증 우회(CVE-2026-128090), DOM 직렬화 이중 해제(CVE-2026-129501), PHP-CGI의 PATH_INFO 처리 범위 밖 읽기·쓰기(CVE-2026-129538)도 포함됐다.

다만 공지와 변경 이력에는 이 중 어느 항목이 CRITICAL 등급인지 따로 표시돼 있지 않다. 영향을 받는 구체적 구성도 릴리스 공지에는 나오지 않았다.

PHP 8.6의 대표 기능은 부분 함수 적용(Partial Function Application)이다. 함수 인수 자리에 `?`나 `...` 자리표시자를 두면 나머지 인수만 받는 클로저가 만들어져, 화살표 함수로 감싸던 콜백 코드를 줄일 수 있다.

경과 시간을 다루는 `\Time\Duration` 클래스와, epoll·kqueue·이벤트 포트·WSAPoll을 활용하는 폴링 API `Io\Poll`도 새로 들어갔다. 이 밖에 값을 범위 안으로 묶는 `clamp()` 함수, 정렬 방향을 나타내는 `SortDirection` 열거형, readonly 속성 기본값 지원이 추가됐다.

## 핵심 포인트

- PHP 8.6.0이 11월 19일 정식 출시됐다
- 같은 날 8.5.13·8.4.28·8.3.37·8.2.36 보안 릴리스가 함께 배포됐다
- 보안팀은 최고 심각도를 CRITICAL로 예고했고, 비기본 설정·드문 구성에서 발생한다고 밝혔다
- 변경 이력에는 원격 코드 실행 가능성이 있는 해제 후 사용, PHP-FPM 요청 스머글링 등이 올라 있다
- 8.6의 대표 기능은 부분 함수 적용, Time\Duration, Io\Poll이다
