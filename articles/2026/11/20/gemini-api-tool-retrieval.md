# 구글, 제미나이 API에 '도구 검색' 기능 미리보기 공개…수백 개 도구 스키마를 필요할 때만 불러와

- 분야: AI 뉴스
- 출처: 구글 공식 블로그
- 원문 링크: https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval
- 발행일: 2026-11-19

## 상세 요약

구글이 11월 19일 제미나이 API에 '도구 검색(Tool Retrieval)' 기능을 도입했다고 공식 블로그에서 밝혔다. 에이전트가 수십~수백 개 도구를 다룰 때, 모든 함수의 매개변수 스키마를 매 요청에 담아 보내지 않고 필요할 때만 불러오게 하는 기능이다. 입력 토큰과 지연 시간을 줄이고 도구 선택 정확도를 높이는 것이 목표다.

쓰는 방법은 간단하다. 요청에 `tool_search` 도구를 추가하고, 미뤄 둘 도구에 `defer_loading: true`를 지정한다. 모델은 미뤄 둔 도구의 이름과 설명만 보고, 매개변수 스키마는 컨텍스트에 들어가지 않는다. 모델이 특정 도구가 필요하다고 판단해 이름으로 요청하면 API가 스키마를 불러와 같은 요청 안에서 함수를 호출한다.

검색은 서버에서 실행되므로 개발자가 별도 인덱스를 만들거나 운영할 필요가 없다. 원격 MCP 서버도 지원해, `mcp_server` 도구에 `defer_loading: true`를 걸면 그 서버가 제공하는 도구 전체를 필요할 때 불러온다. 자체 도구 레지스트리나 임베딩 인덱스가 있다면 `"execution": "client"`로 클라이언트 쪽 검색을 쓸 수도 있다. 이 경우 검색마다 왕복이 한 번 늘지만 대화 도중 새 도구를 노출할 수 있다.

구글은 프리픽스 캐싱과 궁합이 좋다고 설명했다. 미뤄 둔 스키마는 프롬프트 앞부분에 들어가지 않고 불러온 스키마는 뒤에 붙기 때문에, 캐시된 앞부분이 턴마다 그대로 유지된다.

이 기능은 인터랙션 API에서 미리보기로 제공되며 제미나이 3.6 이상과 모든 제미나이 4 모델을 지원한다. 별도 요금은 없고 모델의 표준 토큰 요금이 적용된다. `tool_search`를 켜면 고정된 소량의 입력 토큰이 추가되고 불러온 스키마는 대화가 이어지는 동안 입력으로 과금되므로, 구글은 실제 트래픽으로 이득을 확인해 보라고 권했다.

## 핵심 포인트

- 제미나이 API가 도구 매개변수 스키마를 필요할 때만 불러오는 도구 검색을 지원한다.
- `defer_loading: true`로 도구나 원격 MCP 서버 전체를 지연 로딩할 수 있다.
- 서버 측 검색이 기본이며 클라이언트 측 검색도 선택할 수 있다.
- 인터랙션 API 미리보기로 제공되고 제미나이 3.6 이상·제미나이 4 전 모델이 대상이다.
- 별도 요금은 없지만 검색용 고정 토큰과 불러온 스키마는 입력으로 과금된다.
