# 앤트로픽, 클로드 코드에 실험 기능 '코드 모드' 추가…여러 도구를 자바스크립트로 한 번에 실행

- 분야: AI 뉴스
- 출처: AI타임스
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217565
- 발행일: 2026-11-19

## 상세 요약

앤트로픽이 코딩 에이전트 '클로드 코드'에 '코드 모드(Code Mode)'를 추가했다. 17일(현지시간) 배포된 2.1.323 버전부터 실험 기능으로 들어갔으며, 기본값은 꺼져 있어 이용자가 따로 설정해야 쓸 수 있다.

기존 클로드 코드는 Bash, Read, Edit 같은 도구를 하나씩 호출하고, 결과를 본 뒤 다음 행동을 정했다. 코드 모드에서는 클로드가 자바스크립트 코드를 직접 짜서 실행하고, 그 스크립트 안에서 여러 도구를 연달아 부른다. 서로 독립적인 명령은 병렬로 돌리고, 앞 단계 결과를 다음 단계로 바로 넘길 수 있다.

핵심은 도구 실행 결과 전체를 매번 모델 컨텍스트에 싣지 않는다는 점이다. 중간 결과는 자바스크립트 안에서 걸러 내고 필요한 정보만 모델에 전달해, 모델 호출 횟수와 토큰 사용량을 줄이는 구조다. 함수를 찾아 해당 파일을 고치고 관련 테스트까지 하나의 스크립트로 돌리는 경우, 여러 파일에 같은 변경을 적용하는 경우, 검색 결과를 다시 거르는 경우 등이 활용 예로 소개됐다. 다만 기사에는 실제로 토큰이나 호출이 얼마나 줄었는지 보여 주는 수치는 없다.

실험 단계인 만큼 쓸 수 있는 환경은 좁다. 클로드 코드의 대화형 터미널에서만 작동하고 데스크톱 앱, VS Code 확장, 에이전트 SDK, 클라우드 세션은 지원하지 않는다. 클로드 구독이나 콘솔 계정이 필요하며 일부 클라우드 플랫폼을 통한 이용도 제한된다.

권한 검토 방식도 달라진다. 자동 권한 모드에서는 분류기가 개별 도구 호출이 아니라 자바스크립트 코드 전체를 단위로 검토한다. 이 때문에 실행 중에 동적으로 정해지는 값은 미리 확인하지 못할 수 있다. 반면 스크립트 안에서 일어나는 개별 도구 호출에는 기존 권한 규칙과 보안 훅이 그대로 적용된다.

## 핵심 포인트

- 클로드 코드 2.1.323부터 '코드 모드'가 실험 기능으로 들어갔고 기본값은 꺼져 있다.
- 클로드가 자바스크립트로 여러 도구를 묶어 실행하고 중간 결과를 코드 안에서 처리한다.
- 모델 호출과 토큰 사용을 줄이려는 기능이지만 절감 수치는 공개되지 않았다.
- 대화형 터미널에서만 작동하며 데스크톱·VS Code·SDK·클라우드 세션은 미지원이다.
- 자동 권한 모드에서는 분류기가 스크립트 전체 단위로 검토한다.
