# 코드 호스팅 Codeberg, 등록업체 NameSilo의 도메인 정지로 접속 불가…수 시간 만에 복구 중

## 상세 요약

비영리 오픈소스 코드 호스팅 서비스 Codeberg의 대표 도메인 codeberg.org가 11월 18일 갑자기 접속되지 않았다. Codeberg 공식 상태 계정에 따르면 도메인이 등록업체 NameSilo의 Codeberg 계정에서 아예 사라진 상태였다.

Codeberg는 갱신을 놓친 일이 아니라고 밝혔다. 계정 로그인 기록에 수상한 접속이 없었고, 계정의 도메인 이력에도 관련 기록이 남아 있지 않았다. 처음에는 호스팅 저장소의 규정 위반 문제일 가능성은 낮다고 봤다. NameSilo의 악용 신고 절차에 따른 사전 경고를 받지 못했기 때문에 기술적 오류 쪽에 무게를 뒀다.

이후 확인 결과 도메인이 정지된 것으로 드러났다. 사안은 NameSilo 내부 악용 신고 대응팀으로 넘어갔고, Codeberg는 최종 결정을 기다리고 있다고 전했다. GeekNews에 소개된 한 이용자의 기술 분석에 따르면 WHOIS에는 clientHold와 clientTransferProhibited 상태가 표시됐고, 마지막 갱신 시각은 2026-11-18T05:52:56Z였다. 이 이용자는 DNS 정지가 약 4시간 이어졌다고 추산했다.

Codeberg는 비상 우회책으로 codeberg.eu를 켜는 방안을 검토했다가 접었다. 여러 도메인 지원, 검색 엔진 최적화, 2단계 인증 같은 기술 문제와 함께, 모든 사용자가 git 원격 주소를 바꿔야 하는 부담이 이점보다 크다고 판단했다.

단일 장애 지점을 줄여야 한다는 점은 인정했다. 다만 두 번째 도메인을 제대로 운영하는 것은 몇 시간 안에 할 수 있는 일이 아니라 장기 과제라고 설명했다. 한 답글에서는 재확인 없이 서비스가 정지되는 일은 어느 업체에서나 생길 수 있다며, 앞서 EU 업체 Netcup에서 VPS가 정지된 사례도 언급했다.

이후 도메인은 서서히 복구되고 있으며, 일부 사용자는 DNS 전파를 기다려야 할 수 있다. Codeberg는 큰 불편을 끼쳐 죄송하다고 사과했다. 소개 시점까지 NameSilo 악용 대응팀의 공식 답변은 나오지 않았다.

## 핵심 포인트

- codeberg.org가 등록업체 NameSilo 계정에서 사라지며 접속 불가 상태가 됐다
- 갱신 누락이나 계정 탈취가 아니라 도메인 정지로 확인됐고 사유는 아직 나오지 않았다
- 비상 도메인 codeberg.eu 전환은 git 원격 주소 변경 부담 등으로 하지 않기로 했다
- 이용자 추산으로 DNS 정지는 약 4시간 이어졌고 도메인은 복구 중이다
- Codeberg는 단일 도메인 의존을 줄이는 장기 과제를 인정했다
