# 텐센트 'Hy4' 출시…공격용 보안 자료 빼고 학습, 중국 최상위권 진입 선언

- 분야: AI 뉴스
- 출처: AI타임스(텐센트 공식 발표, Vals AI 평가 인용)
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217039
- 발행일: 2026-11-05

## 상세 요약

텐센트가 4일(현지시간) 공식 발표를 통해 차세대 AI 모델 'Hy4'를 내놓았다. 8월에 공개한 'Hy4 프리뷰'의 후속으로, 사전학습과 사후학습 규모를 모두 키웠다. 텐센트는 코딩, 에이전트, 브라우저 사용에서 Z.ai, 문샷 AI, 딥시크의 최신 모델과 대등한 수준에 올랐다고 주장했다.

눈에 띄는 대목은 사이버 보안 학습 데이터를 제한한 점이다. 취약점 분석과 보안 결함 수정 같은 방어 목적의 데이터를 중심으로 학습했고, 시스템 침입이나 취약점 악용에 바로 쓸 수 있는 공격 자료는 제외했다. 역공학과 침투 테스트 자료는 방어 분석에 필요한 범위까지만 사용했다고 한다.

모델은 전체 7700억 매개변수, 추론 시 활성 매개변수 약 490억 개의 전문가 혼합(MoE) 구조이며, 문맥은 최대 100만 토큰까지 처리한다. Hy4 계열 가운데 처음으로 이미지 이해 기능을 갖춰 복잡한 차트 분석과 수학적 시각 추론이 가능해졌다. CLI와 GUI 양쪽의 컴퓨터 사용 기능도 더했고, 블렌더와 CAD, 여러 앱을 오가는 장기 작업 계획, 프런트엔드·게임 개발 학습도 강화했다.

수치는 측정 주체에 따라 온도 차가 있다. 전문가 213명이 579개 과제를 평가한 금융 평가에서 Hy4는 3.04점으로 딥시크 V4.1 플래시(2.97점), 키미 K3.1 프로와 GLM-5.3(각 2.68점)을 앞섰고, 자체 측정 환각률은 프리뷰의 12.95%에서 7.2%로 낮아졌다. 반면 제3자인 Vals AI 평가에서는 전체 정확도 59.35%로 33개 모델 중 13위, 오픈웨이트 모델 중 4위였다. 키미 K3.1 프로(62.52%), 딥시크 V4.1 플래시(61.26%), GLM-5.3(59.73%)이 그 앞에 있다. 텐센트도 연구 수준의 수학, 장기 코딩, 모델 자기개선, 고급 시각 품질 검증에서는 최상위 폐쇄형 모델과 격차가 크다고 인정했다.

안전성 면에서는 텐센트 산하 보안 조직인 쉬안우 랩과 킨 시큐리티 랩이 암호 분석, 바이너리 난독화 해제, 취약점 악용을 시험한 결과 주목할 만한 공격 능력 위험은 없었다고 밝혔다. 생물학 분야에서는 기초 지식을 갖췄지만 복잡한 실험 설계는 최상위 모델에 못 미친다고 평가했다. 다만 모두 텐센트 자체 평가이고, 안전성 결과를 담은 시스템 카드는 아직 공개되지 않았다.

정식 모델의 가중치도 공개 전이다. 텐센트는 가중치를 시스템 카드와 함께 나중에 배포할 계획이며, 더 빠르고 저렴한 경량 모델 'Hy4 플래시'도 준비 중이다. 현재는 텐센트 클라우드, 코드버디, 워크버디, 위안바오에서 쓸 수 있고, API 가격은 프리뷰와 같은 수준으로 유지된다. 워크버디와 코드버디에서는 15일까지 일정량을 무료로 제공한다.

## 핵심 포인트

- 공격에 바로 쓸 수 있는 자료를 학습에서 제외하고 방어 데이터 중심으로 학습
- MoE 구조 7700억 매개변수, 문맥 100만 토큰, 계열 최초 이미지 이해 지원
- 자체 금융 평가는 비교 모델을 앞섰지만 Vals AI 평가는 33개 중 13위, 오픈웨이트 중 4위
- 정식 모델 가중치와 시스템 카드는 아직 미공개, 경량 모델 Hy4 플래시 예고
- 텐센트도 최상위 폐쇄형 모델과의 격차를 인정
