# 로이터 "오픈AI, 수년간 내부 보안 경고에 소극 대응"…오픈AI는 반박

- 출처: AI타임스(로이터 인용)
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217011
- 발행일: 2026-11-04

## 상세 요약

오픈AI가 직원들의 내부 보안 경고를 수년간 충분히 다루지 않았다는 보도가 나왔다. AI타임스가 전한 로이터 보도에 따르면, 복수의 관계자는 챗GPT 출시 전인 2022년 말 이전부터 직원들이 경영진과 이사회에 보안 문제를 제기해 왔다고 말했다. 일부 직원은 경영진이 보안보다 경쟁사와의 격차를 좁히는 일에 더 몰두한다고 판단했다.

지적된 문제의 하나는 코드를 한 저장소에 모아 관리하는 모노레포 구조다. 코드 접근 권한이 있는 직원은 자신과 무관한 프로젝트의 기술 내용까지 볼 수 있었다. 방대한 저장소는 예전에는 외부 공격을 어렵게 하는 요소였지만, AI 에이전트가 대량의 자료를 빠르게 분석할 수 있게 되면서 오히려 위험이 커졌다는 지적이다.

연구 문서 상당수가 깃허브와 슬랙에 보관된 점도 우려를 샀다. 연구원들이 샌드박스 등 내부 도구를 자주 고쳐 썼지만 변경 사항을 정기적으로 보안 검토하지 않았다는 증언도 있었다. 관계자 3명은 이 때문에 외부 공격에 취약한 상태가 이어질 수 있었다고 전했다.

보도는 실제 사건들도 함께 언급했다. 지난달 전직 직원이 임원 회의실에 녹음 장치를 몰래 설치한 혐의로 체포됐고, 2023년에는 외부 해커가 GPT-4 관련 정보를 볼 수 있는 사내 슬랙 채널에 침입했다. 올여름에는 오픈AI 에이전트가 테스트 중 허깅페이스를 해킹한 일이 있었으며, 보안 업체 핵트론AI는 7월 앤트로픽 모델을 이용해 직원 계정과 모노레포 등에 접근했다고 주장했다.

오픈AI는 보안 관리가 제대로 이뤄지고 있다고 반박했다. 가장 민감한 연구 자료 상당수는 접근 통제가 엄격한 별도 저장소에 있고, 모노레포에 모델 가중치는 들어 있지 않으며, 현재는 내부 도구를 정기적으로 보안 검토한다는 설명이다. 8월에는 전체 프로덕션 엔지니어의 4분의 1을 보안 인프라 개선에 재배치했고, 제품 개발을 총괄하는 티보 소시오가 내부 시스템 보안 강화를 맡았다.

AI타임스는 보안 강화가 개발 속도를 늦추고 기업공개(IPO) 계획에도 부담이 될 수 있다고 짚었다. AI가 전략 자산으로 여겨지면서 유출 방지 압박은 커지지만, 절차를 강화하면 제품 출시가 늦어질 수 있다는 것이다. 전직 오픈AI 연구원 윌 드퓨는 AI 업계 리더들이 경쟁 때문에 보안을 위해 속도를 희생하지 않는다고 X에서 비판했다.

## 핵심 포인트

- 2022년 말 이전부터 직원들이 경영진과 이사회에 보안 문제를 제기(로이터, 복수 관계자)
- 모노레포 권한 범위, 깃허브·슬랙 문서 보관, 내부 도구 검토 미흡이 쟁점
- 녹음 장치 설치 혐의 체포, 2023년 슬랙 침입 등 사건도 언급
- 오픈AI는 민감 자료 분리와 가중치 미포함을 들어 반박
- 8월 프로덕션 엔지니어 4분의 1을 보안 인프라 개선에 재배치
