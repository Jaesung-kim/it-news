# 오픈AI '이미지스 2.6' 공개…챗GPT에서 GIF 생성, 이미지 속도 50% 향상

- 분야: AI 뉴스
- 출처: AI타임스, OpenAI, The Verge
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217038
- 오픈AI 발표: https://openai.com/index/introducing-images-2-6
- 발행일: 2026-11-04(현지시간 발표), 2026-11-05(AI타임스)

## 상세 요약

오픈AI가 4일(현지시간) 이미지 생성 모델 '이미지스 2.6'을 공개하고 챗GPT에 애니메이션 GIF 기능을 넣었다. 정지 이미지에 머물던 챗GPT의 이미지 생성이 움직이는 결과물까지 넓어진 것이다. 제품 이름도 '이미지스'로 바뀌었지만, 개발자용 API 모델 이름에는 'GPT 이미지'가 그대로 남는다.

GIF는 문장으로 지시하거나 사진을 올려 만들 수 있다. 재생 속도를 조절하고 프레임을 하나씩 고칠 수 있으며, 결과물을 다른 사람과 공유할 수도 있다. AI타임스는 간단한 스케치를 움직이는 캐릭터로 바꾸는 사례와 함께 브랜드 마스코트, 소셜미디어 밈, 광고 애니메이션을 활용처로 꼽았다.

성능 면에서는 9월에 나온 2.5보다 생성 속도가 50% 빨라졌다. 편집을 반복해도 캐릭터 외형, 제품 디자인, 브랜드의 시각적 특징을 일관되게 유지하며, 포스터와 제품 이미지의 레이아웃 품질도 나아졌다는 설명이다.

개발자용으로는 두 모델이 나뉜다. 'GPT 이미지 2.6 플레어'는 빠른 생성에 맞춘 모델로, 낮은 품질 설정에서 이미지 한 장을 최소 6초 만에 만든다. 'GPT 이미지 2.6 선버스트'는 고품질과 정밀 편집에 초점을 맞췄다. API에는 수정할 영역을 표시하는 마크업, 웹·앱·인쇄용 SVG 내보내기, 생성 전 계획 수준을 조절하는 '복잡도' 설정이 추가됐다.

이미지스 2.6은 무료 이용자를 포함한 모든 요금제의 챗GPT와 코덱스 이용자에게 웹, 데스크톱, 모바일로 제공된다. 다만 GIF 생성은 단계적으로 배포되고 있어 아직 쓸 수 없는 계정도 있다. AI타임스는 개발자가 두 모델을 API로 쓸 수 있다고 전했지만, 기사에 실린 오픈AI 게시물에는 "coming to the API"라고 적혀 있어 API 제공 시점은 공식 문서로 확인할 필요가 있다.

오픈AI에 따르면 챗GPT, 코덱스, API를 합친 이미지 생성량은 GIF를 포함해 주당 40억 장을 넘어섰다. 9월의 주당 30억 장보다 늘어난 수치다. 이전 버전인 2.5의 선버스트와 플레어는 아티피셜 애널리시스의 이미지 생성 평가에서 1, 2위에 올라 있지만, 2.6은 아직 이 평가에 포함되지 않아 성능을 제3자 수치로 비교할 수는 없다.

## 핵심 포인트

- 챗GPT에서 프롬프트나 사진으로 GIF를 만들고 속도와 개별 프레임을 편집할 수 있음
- 이미지 생성 속도는 2.5 대비 50% 향상(오픈AI 발표)
- API 모델은 속도 중심 플레어와 품질 중심 선버스트 두 가지
- 무료 포함 전 요금제에 제공되지만 GIF는 단계적 배포
- 주간 이미지 생성량 40억 장 돌파, 9월 30억 장에서 증가
