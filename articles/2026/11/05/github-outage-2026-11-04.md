## 상세 요약

깃허브에서 11월 4일 약 2시간 동안 오류 증가와 간헐적 실패가 이어졌다. 깃허브 상태 페이지에 따르면 첫 보고는 09시 49분(UTC)이고 종료는 11시 50분이다. 한국 시간으로는 같은 날 18시 49분부터 20시 50분까지다.

장애 범위는 Git 작업, API 요청, 이슈, 풀 리퀘스트, 액션 등 5개 서비스였다. 처음에는 Git 작업·이슈·풀 리퀘스트의 성능 저하로 시작했고, 09시 50분 액션, 09시 53분 풀 리퀘스트 가용성 저하, 11시 11분 API 요청 성능 저하가 차례로 추가됐다. 11시 17분 공지는 일부 요청이 실패하거나 지연될 수 있다고 안내했다.

복구는 단계적으로 이뤄졌다. 11시 30분 API 요청, Git 작업, 이슈, 풀 리퀘스트의 영향이 완화됐고, 11시 43분 액션이 뒤를 이었다. 깃허브는 안정성을 지켜본 뒤 11시 50분 사고 종료를 선언했다.

원인은 아직 공개되지 않았다. 상태 페이지에는 원인이나 계기가 적혀 있지 않고, 상세한 근본 원인 분석을 준비되는 대로 공유하겠다는 안내만 있다. 후속 분석이 나오기 전까지 영향 규모와 재발 방지책은 확인할 수 없다.
