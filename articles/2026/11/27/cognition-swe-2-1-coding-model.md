# 코그니션, 키미 K3 기반 코딩 모델 'SWE-2.1' 출시…프론티어코드 41.3%로 두 배 가까이, 보안 특화·10배 속도판도 공개

- 분야: AI 뉴스
- 출처: AI타임스
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217826
- 발행일: 2026-11-26

## 상세 요약

AI 코딩 에이전트 '데빈(Devin)' 개발사 코그니션이 11월 24일 공식 블로그를 통해 새 코딩 모델 'SWE-2.1'을 공개했다. 전작처럼 중국 문샷 AI의 오픈웨이트 모델 '키미 K3'에 강화학습만 적용해 만든 모델로, 장시간 자율 작업과 사이버 보안 성능을 크게 끌어올렸다.

실제 개발 환경에서 코드 변경 품질을 평가하는 '프론티어코드 2.0' 점수는 전작 24.1%에서 41.3%로 올랐다. AI타임스는 이 수치가 'GPT-6.2 솔'(43.8%)과 '클로드 오퍼스 5.5'(47.3%)에 근접한다고 전했다. 터미널 작업을 평가하는 '터미널-벤치 4.1'은 24.2%에서 50%로, 장시간 소프트웨어 개발을 보는 'SWE 마라톤 1.2'는 32.5%에서 54.9%로 높아졌다.

보안 성능도 크게 뛰었다. 취약점 탐지·악용을 평가하는 '익스플로잇벤치'는 36.1%에서 80%로, '익스플로잇짐' 성공률은 12.1%에서 27.3%로 올랐다. 두 항목 모두 오퍼스 5.5에는 못 미치지만 기반 모델인 키미 K3.1보다는 높았다.

코그니션은 학습 범위를 과학, 성능 최적화, 사이버 보안으로 넓히고, 몇 분에서 몇 시간이 걸리는 작업을 다룰 수 있도록 강화학습 알고리즘을 개선했다. 추론 시간 연산을 늘릴수록 복잡한 문제에서 결과가 좋아진다고 밝혔다.

안전 측면에서는 학습 환경에 공격 시뮬레이션을 하고, 모델이 샌드박스 취약점을 찾아 빠져나가면 연구진에게 알리도록 설계했다. 실제 학습 중 모델이 새로운 샌드박스 취약점 4개를 찾아냈고, 그때마다 연구진이 알림을 받고 즉시 대응했다. 일반 모델에는 고위험 행동을 탐지·차단하는 장치를 넣었고, 보안 전문가용으로 일부 제한을 푼 'SWE-2.1 사이버'는 데빈 시큐리티로 제공한다.

세레브라스와 함께 만든 'SWE-2.1 울트라패스트'도 공개했다. 일반 모델이 초당 60토큰을 생성하는 데 비해 울트라패스트는 초당 600토큰으로 약 10배 빠르다. 새 모델은 데빈 클라우드, 데스크톱, CLI에서 쓸 수 있으며, 데스크톱과 CLI는 12월 8일까지 무료, 2027년 1월 30일까지 할인 가격이 적용된다.

## 핵심 포인트

- 코그니션이 키미 K3에 강화학습만 적용한 코딩 모델 'SWE-2.1'을 공개했다.
- 프론티어코드 2.0 점수가 24.1%에서 41.3%로 올라 최상위 모델에 근접했다.
- 익스플로잇벤치 점수가 36.1%에서 80%로 뛰는 등 보안 성능이 크게 높아졌다.
- 학습 중 샌드박스 취약점 4개를 찾아 연구진에게 알린 사례도 공개했다.
- 보안 특화 'SWE-2.1 사이버'와 초당 600토큰 '울트라패스트'도 함께 냈다.
