# 오픈AI, 연산 중에도 기업 데이터 못 보게 하는 '프라이빗 추론' 시험 운영…기밀 컴퓨팅 적용, 소수 고객 대상

- 분야: AI 뉴스
- 출처: AI타임스
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217828
- 발행일: 2026-11-26

## 상세 요약

오픈AI가 기업 고객의 민감한 데이터를 AI 연산 과정에서도 보호하는 '프라이빗 추론(Private Inference)'을 소수 고객을 대상으로 시험 운영하기 시작했다. 샘 올트먼 CEO가 11월 25일 X를 통해 알렸다. 그는 "We're now testing Private Inference, our latest offering as part of OpenAI Private Intelligence"라며 기업용 데이터 보호 체계 '프라이빗 인텔리전스'의 새 기능이라고 소개했다.

핵심 기술은 기밀 컴퓨팅이다. AI 연산을 하드웨어로 격리된 환경에서 실행해, 프롬프트를 처리하고 답변을 생성하는 동안 오픈AI 시스템 운영자조차 고객의 실제 데이터에 접근하지 못하게 하는 것이 목표다.

AI타임스는 이번 기능이 기존 보호 방식과 초점이 다르다고 설명했다. 그동안은 입력 데이터를 저장하지 않는 데 무게를 뒀다면, 이번에는 데이터를 처리하는 순간까지 접근을 막는다는 것이다.

오픈AI는 이미 프롬프트와 응답을 저장하지 않는 '제로 데이터 보존(ZDR)'을 지원하고 있다. 9월부터는 직원이 내용을 보지 않고 자동으로 안전성 검토를 하는 '프라이빗 안전 처리(Private Safety Processing)'를 API 고객에게 단계적으로 적용해 왔다.

지원 모델, 가격, 정식 출시 일정은 공개되지 않았다. 오픈AI는 더 강력한 개인정보 보호 기능이 최첨단 AI를 훨씬 더 많은 업무에 활용할 수 있게 할 것이라는 입장이다.

## 핵심 포인트

- 오픈AI가 '프라이빗 추론'을 소수 기업 고객 대상으로 시험 중이다.
- 하드웨어 격리 기밀 컴퓨팅으로 처리 중 데이터 접근을 차단한다.
- 운영자도 프롬프트와 응답 내용을 볼 수 없도록 하는 것이 목표다.
- 기존 ZDR, 프라이빗 안전 처리에 이은 기업용 보호 기능이다.
- 지원 모델, 가격, 정식 출시 일정은 공개되지 않았다.
