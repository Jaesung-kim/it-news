# 앤트로픽 "개별 뉴런만 봐도 숨은 행동 찾는다"…감사 정확도 40%→75%, 백도어 작동 단어 54% 추적

## 상세 요약

앤트로픽의 재스민 숀, 리사 던랩 연구진이 11월 23일(현지시간) '뉴런 기반 해석 가능성으로 돌아가기'라는 제목의 연구 두 편을 공개했다. 별도 분석 모델을 훈련하지 않고 기존 모델의 내부 연산과 가중치를 직접 들여다봐 숨겨진 위험 행동을 찾는 방식으로, AI의 답변이나 사고 과정(CoT)에 기대는 안전성 감시의 한계를 보완하겠다는 취지다.

그동안 앤트로픽과 오픈AI, 구글 딥마인드는 얽힌 정보를 사람이 이해할 수 있는 개념 단위로 나누는 희소 오토인코더(SAE)로 모델 내부를 분석해 왔다. 개별 뉴런은 여러 무관한 개념에 반응하고 지식도 여러 뉴런에 흩어져 있어 직접 해석하기 어렵다고 여겨졌기 때문이다.

첫 번째 연구는 뉴런이 어떤 입력에 반응하는지뿐 아니라 활성화될 때 모델 안에 어떤 정보를 더하는지까지 보면 역할을 상당 부분 파악할 수 있다고 주장했다. 4개 모델의 중간층 뉴런을 표본 조사하자, 한 번의 활성화로 무관한 두 개념을 동시에 반영하는 경우는 1% 이하였다. 환각 분석에도 적용해, '백년의 고독' 작가를 묻는 질문에서 가브리엘 가르시아 마르케스 관련 뉴런을 지우자 모델이 호르헤 루이스 보르헤스라고 답했다. 정답 정보가 모자라면 남은 연관 정보로 그럴듯한 답을 지어낸다는 설명이다.

두 번째 연구는 안전성 활용을 다뤘다. 500개 개념 탐지 실험에서 개별 뉴런 분석이 SAE 기반 분석보다 나았고, 정답 데이터 없이도 16개 안전성 평가 세트 중 11개에서 텍스트 검색 방식보다 유해 콘텐츠를 잘 찾았다. 다만 정답 데이터로 따로 훈련한 탐지기에는 대체로 못 미쳤다.

미세조정으로 새 행동을 가르치면 관련 정보를 이미 처리하던 뉴런의 활성도가 높아지는 경향도 확인됐다. 이를 이용해 기본 모델과 미세조정 모델의 가중치 차이를 비교하자, 백도어 모델 74개에서 작동 문구 단어의 평균 54%를 상위 50개 후보 안에서 찾아냈다. 숨겨진 행동을 넣은 58개 모델을 포함한 감사 실험에서는 답변만 분석할 때 40%였던 정확도가 내부 개입과 뉴런 분석을 함께 쓰자 75%로 올랐다.

사이버 보안 지식을 잊도록 훈련한 모델 23개 가운데 14개는 객관식 정답률이 떨어졌지만, 일부는 뉴런 수십 개만 원래대로 되돌려도 정답 회상이 상당 부분 살아났다. 위험 지식을 실제로 지운 것이 아니라 드러나지 않게 억제했을 가능성이 있다는 뜻이다.

기사는 뉴런 분석이 기존 해석 도구를 대체하기보다 보완하는 역할을 할 것으로 봤다. 실험은 70억~320억 매개변수의 오픈웨이트 모델에 한정돼, 최첨단 대형 모델에서도 같은 효과가 나는지는 추가 검증이 필요하다.

## 핵심 포인트

- 앤트로픽이 SAE 없이 개별 뉴런을 직접 분석하는 연구 2편을 공개했다.
- 16개 안전성 평가 세트 중 11개에서 텍스트 검색보다 유해 콘텐츠 탐지가 우수했다.
- 감사 실험 정확도는 답변 분석 40%에서 뉴런 분석 병행 시 75%로 올랐다.
- 언러닝 모델 일부는 뉴런 수십 개 복원만으로 지식이 되살아났다.
- 실험은 70억~320억 매개변수 오픈웨이트 모델에 한정됐다.
