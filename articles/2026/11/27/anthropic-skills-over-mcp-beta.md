# 앤트로픽, MCP 서버로 업무 노하우 전달하는 '스킬' 공개 베타…장시간 작업 '태스크'·승인 요청 '엘리시테이션'은 정식 출시

## 상세 요약

앤트로픽은 11월 24일(현지시간) 공식 블로그에서 클로드와 클로드 코드에 'MCP를 통한 스킬(Skills over MCP)' 기능을 공개 베타로 내놨다고 밝혔다. AI 에이전트를 외부 도구·데이터에 연결하는 표준인 모델 컨텍스트 프로토콜(MCP)에, 도구를 어떻게 잘 쓰는지에 관한 업무 노하우까지 실어 보내겠다는 것이다.

MCP는 앤트로픽이 2024년 11월 공개한 뒤 오픈AI와 마이크로소프트 등의 지원을 받아 에이전트 연결 표준으로 자리 잡았다. 현재 MCP SDK 월간 다운로드는 7억 회를 넘고, 클로드용 MCP 커넥터는 1만 개 이상이다. 다만 지금까지 MCP 서버는 에이전트가 쓸 수 있는 도구 목록만 알려줬다.

스킬은 특정 업무 수행 방법을 담은 지침 패키지로, 도구 활용법과 단계별 절차, 조직별 업무 지침을 담을 수 있다. 클로드는 필요할 때만 스킬을 불러와 토큰 사용량을 줄이고, 스킬은 서버와 함께 갱신돼 사용자가 따로 설치하거나 관리할 필요가 없다. 쇼피파이는 클로드가 판매자의 온라인 스토어를 설계·수정하는 데 필요한 지침을 스킬로 제공한다.

함께 정식 출시된 '태스크(Tasks)'는 MCP 서버가 오래 걸리는 업무를 백그라운드에서 처리하는 동안 클로드가 다른 일을 계속하게 해준다. '엘리시테이션(Elicitation)'은 서버가 작업 중 사용자에게 필요한 정보를 묻거나 결제·데이터 삭제 같은 중요한 작업 전에 승인을 받도록 한다. PDF·스프레드시트·이미지를 모델의 컨텍스트 창을 거치지 않고 서버에 바로 넘기는 파일 업로드 기능도 출시를 앞두고 있다.

스킬은 프로·맥스·울트라 요금제에서 기본으로 켜지고, 팀 요금제는 관리자 승인이 필요하며, 엔터프라이즈 요금제에는 추후 적용된다.

앤트로픽은 이 기능들이 개방형 MCP 규격과 확장 기능에 들어가 있어 이를 지원하는 다른 AI 서비스에서도 쓸 수 있다고 설명했다. 클로드가 MCP 서버를 또 하나의 에이전트처럼 활용해 전문 지식을 얻고 업무를 위임할 수 있게 됐다는 것이 회사 측 설명이다.

## 핵심 포인트

- 'MCP를 통한 스킬'이 클로드·클로드 코드에 공개 베타로 출시됐다.
- 스킬은 필요 시에만 로드되고 서버와 함께 자동 갱신된다.
- 장시간 작업용 '태스크', 승인·정보 요청용 '엘리시테이션'은 정식 출시됐다.
- 프로·맥스·울트라는 기본 활성화, 팀은 관리자 승인, 엔터프라이즈는 추후 적용이다.
- 개방형 MCP 규격에 포함돼 다른 AI 서비스에서도 쓸 수 있다.
