# 구글, 외부 AI 에이전트의 지메일·드라이브 접근에 요금 부과…하루 5000건 무료, 2027년 4월부터 1000건당 최대 0.5달러

- 분야: AI 뉴스
- 출처: AI타임스(구글 개발자 문서 인용)
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217820
- 발행일: 2026-11-26

## 상세 요약

구글이 외부 AI 에이전트가 지메일, 구글 드라이브 등 워크스페이스 데이터에 접근하는 데 사용량 제한과 유료 요금제를 도입한다. AI타임스에 따르면 구글은 11월 24일 공식 개발자 문서를 통해 워크스페이스 API와 모델 컨텍스트 프로토콜(MCP) 서버에 '표준(Standard)'과 '확장(Scaled)' 두 등급을 두겠다고 밝혔다.

표준 등급에서는 지메일, 캘린더, 드라이브, 문서, 스프레드시트 MCP 서버를 제품별·개발 프로젝트별로 하루 5000건까지 무료로 쓸 수 있다. 다만 일부 MCP 도구는 한 번 호출해도 여러 건의 요청으로 계산될 수 있다. 구글은 활발히 활동하는 워크스페이스 개발자 대부분이 무료 한도 안에 머물 것으로 본다.

일정은 두 단계다. 2027년 2월 1일부터 에이전트가 워크스페이스 데이터에 접근할 때 MCP 이용 요건이 적용되며, 기존 REST API를 직접 부르는 에이전트는 표준 등급 한도를 넘을 수 없다. 4월 1일부터는 확장 등급 과금이 시작된다. REST API 이용자는 하루 무료 한도를 넘는 사용량에만 요금을 내지만, 지메일·캘린더·드라이브 MCP 이용자는 확장 등급으로 옮기면 첫 요청부터 요금이 붙는다.

요금은 작업 종류에 따라 1000건당 0.10~0.50달러다. 이메일 읽기·발송과 파일 생성은 0.20달러, 파일 검색과 일정 관리는 0.25달러, 파일 다운로드와 이메일 대화 검색은 0.50달러로 책정됐다.

무료 한도가 사용자나 에이전트 단위가 아니라 개발 프로젝트 단위로 적용된다는 점이 변수다. 수천 명의 고객을 상대하는 AI 기업은 한도를 금방 소진할 수 있다. 구글은 에이전트의 데이터 접근 수요가 급증하는 상황에서 안정성, 보안, 개인정보 보호를 관리하기 위한 조치라고 설명했다.

AI타임스는 이를 '디지털 통행료'에 빗대며, 대규모 에이전트 서비스 운영사가 이제 모델 비용뿐 아니라 데이터 접근 비용까지 따져야 하게 됐다고 평가했다.

## 핵심 포인트

- 구글이 워크스페이스 API·MCP 서버에 표준·확장 두 등급을 도입한다.
- 표준 등급은 제품·프로젝트별로 하루 5000건까지 무료다.
- 2027년 2월 MCP 요건 적용, 4월부터 확장 등급 과금이 시작된다.
- 요금은 작업 종류에 따라 1000건당 0.10~0.50달러다.
- 무료 한도가 프로젝트 단위라 대형 에이전트 서비스는 비용 부담이 커진다.
