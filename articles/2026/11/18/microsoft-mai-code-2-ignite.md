# MS, 코딩 모델 'MAI 코드 2' 공개…클로드 오퍼스급 성능을 비용 5%로

- 분야: AI 뉴스
- 출처: AI타임스
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217511
- 발행일: 2026-11-18

## 상세 요약

마이크로소프트(MS)가 17일(현지시간) 샌프란시스코에서 열린 연례 행사 '이그나이트 2026'에서 자체 코딩 모델 'MAI 코드 2'를 공개했다. 경량형 'MAI 코드 2 플래시', 보안 특화 'MAI 사이버 2 플래시', 에이전트 판단용 '마이크로소프트-디시전-1.1'도 함께 내놓으며 외부 모델 의존도를 낮추는 전략을 분명히 했다.

MAI 코드 2는 대규모 코드 저장소 분석, 여러 파일에 걸친 기능 수정, 버그 해결, 테스트와 검증을 수행한다. 화면 캡처나 UI 시안을 보고 웹·앱 화면을 만드는 작업도 지원한다. 전체 2조8000억개 매개변수 중 추론 때 800억개만 쓰는 전문가 혼합(MoE) 구조이며, 최대 105만 토큰 문맥과 이미지 입력을 지원한다. 약 50조 토큰으로 사전학습한 뒤 깃허브 코파일럿의 실제 개발 환경에서 강화학습을 거쳤다.

MS 자체 평가에 따르면 4개 코딩 벤치마크 평균에서 'GPT-6.1 솔' 대비 98% 성능을 비용 40% 수준으로 냈다. '클로드 오퍼스 5.5'와 비교하면 성능은 96%, 비용은 5%에 그쳤다. 평가자 258명이 참여한 UI·게임·데이터 시각화 블라인드 평가에서는 67%가 GPT-6 솔보다 MAI 코드 2의 결과물을 택했다. 다만 비용 비교에는 50% 프로모션 가격이 적용됐다.

MAI 코드 2 플래시는 3980억개 중 120억개 매개변수를 활성화하는 경량 모델로, 'GPT-6 루나'와 '클로드 하이쿠 5.5'에 근접한 코딩 성능을 훨씬 낮은 비용으로 낸다고 MS는 설명했다. AT&T는 5G 네트워크 분석 작업에서 GPT-6.1 솔보다 나은 성능을 50분의 1 비용으로 얻었다고 밝혔다.

보안 모델 MAI 사이버 2 플래시는 취약점 탐지·재현 평가 '사이버짐-E2E'에서 92.3%를 기록해 GPT-6 아스트라(91.5%)와 비슷한 수준이었고, 작업당 비용은 2%에 못 미쳤다. 다음 달 중순부터 일부 고객의 MS 보안 에이전트 시스템에 통합된다. 디시전-1.1은 도구 선택과 작업 분류 같은 간단한 판단을 빠르고 싸게 처리하는 모델로, 이미 4000곳 이상의 고객이 썼고 이번에 이미지 입력이 추가됐다.

MAI 코드 2와 플래시는 깃허브 코파일럿에서 바로 쓸 수 있고, 플래시는 마이크로소프트 파운드리에서도 제한적으로 제공된다. MS는 기업 고객에게 모델 가중치를 라이선스로 제공하는 'MAI 라이선스드 웨이츠' 전략도 발표했다. 무스타파 술레이만 MS AI CEO는 로이터 인터뷰에서 "이번 성과는 단일 모델에 그치지 않는다"고 말했다.

외부 모델 사용료 부담을 줄여 코파일럿의 수익성을 높이려는 MS의 의도가 드러난 발표다. 성능·비용 수치가 모두 MS 자체 평가라는 점은 외부 검증으로 확인할 필요가 있다.

## 핵심 포인트

- MS가 이그나이트 2026에서 MAI 코드 2·코드 2 플래시·사이버 2 플래시·디시전-1.1을 공개했다.
- MAI 코드 2는 2조8000억 매개변수 MoE 모델로 105만 토큰 문맥을 지원한다.
- 클로드 오퍼스 5.5 대비 성능 96%, 비용 5%라고 MS는 밝혔다(프로모션 가격 기준).
- 사이버 2 플래시는 사이버짐-E2E 92.3%로 GPT-6 아스트라와 비슷한 수준이다.
- 깃허브 코파일럿에서 바로 쓸 수 있고, 가중치 라이선스 판매 전략도 내놨다.
