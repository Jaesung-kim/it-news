# AWS, 여러 AI 에이전트를 지휘하는 '키로 봇' 출시…역할별 기억·예약 작업 지원

## 상세 요약

아마존웹서비스(AWS)가 5일(현지시간) 공식 블로그를 통해 AI 개발 환경 '키로 크루(Kiro Crew)'에서 '키로 봇(Kiro Bots)'을 제공하기 시작했다고 밝혔다. 여러 AI 에이전트의 작업을 조율하고 반복적인 개발 업무를 맡아 처리하는 기능으로, 개발자가 에이전트를 하나하나 감독해야 하는 부담을 덜어 주는 것이 핵심이다.

키로 봇은 특정 역할을 맡는 전담 봇 형태다. 봇마다 독립된 기억과 작업 공간을 갖고, 하위 에이전트를 병렬로 돌리면서 진행 상황과 후속 작업을 추적한 뒤 결과를 하나의 대화 스레드로 모은다. 작업이 계획에서 벗어나면 방향을 다시 잡고, 판단이 필요한 대목에서는 개발자에게 물으면서 다른 작업을 이어 간다.

반복 업무 자동화도 지원한다. "밤사이 생긴 빌드 오류를 조사해라", "매주 금요일 릴리스 노트를 써라"처럼 자연어로 일정을 정할 수 있다. 봇은 과거 결정과 개발자의 피드백을 저장해 다음 작업에 반영하는데, 모델 자체를 다시 학습시키는 방식은 아니다. 활용 예로는 새 이슈 분류와 중복 확인, 빌드·테스트 오류 감시, 코드 리뷰, 배포 전 점검이 제시됐다.

권한은 봇별로 정하고 특정 작업에만 승인을 요구하도록 설정할 수 있다. 기본값은 작업마다 승인을 받지 않는 방식이다. 개발자는 봇의 기억을 보고 고치거나 지울 수 있고, 대시보드로 진행 상황을 볼 수 있다. 지휘 역할의 봇에는 성능 좋은 모델을, 하위 작업에는 빠르고 저렴한 모델을 쓰는 식의 조합도 가능하며, 개발자 PC나 별도 서버, AWS EC2에서 실행할 수 있다.

다만 AWS는 생산성 향상이나 작업 성공률에 대한 벤치마크를 내놓지 않았다. AI타임스는 커서와 앤트로픽도 코딩 에이전트에 예약 실행과 기억 기능을 제공하고 있다며, 비용과 정확도, 안전성은 실제 사용에서 검증이 필요하다고 짚었다.

## 핵심 포인트

- 키로 크루 안에서 역할별 전담 봇이 하위 에이전트를 병렬로 지휘
- 봇마다 독립된 기억·작업 공간, 과거 결정과 피드백을 저장해 재사용
- 자연어 예약 작업 지원, 개발자 PC·별도 서버·EC2에서 실행
- 봇별 권한 설정 가능하나 기본값은 작업별 승인 없음
- 생산성·성공률 벤치마크는 미공개
