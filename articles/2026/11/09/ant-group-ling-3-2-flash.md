# 앤트그룹, 멀티모달 '링 3.2 플래시' 공개…시각 이해 평가 3종서 클로드 오퍼스 5 앞서

- 분야: AI 뉴스
- 출처: AI타임스
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217146
- 발행일: 2026-11-08

## 상세 요약

중국 앤트그룹의 링 개발팀이 5일 멀티모달 AI 모델 '링 3.2 플래시(Ling-3.2-flash)'를 공개했다. 이미지와 동영상을 이해하고 복잡한 작업을 수행하는 모델로, 저렴한 사용료와 긴 컨텍스트를 내세워 기업용 AI 에이전트 시장을 겨냥했다.

모델은 전문가 혼합(MoE) 구조로 총 5600억 개의 매개변수를 갖췄지만, 추론 때는 약 250억 개(전체의 약 4.5%)만 활성화한다. 컨텍스트 창은 최대 100만 토큰이다.

앤트그룹이 자체 측정한 결과로는 일부 시각 이해 평가에서 앤트로픽의 '클로드 오퍼스 5'를 앞섰다. 복잡한 문서 구조·내용 이해를 보는 옴니독벤치 1.5에서 92.21점(오퍼스 5는 90.56점), 시각 추론 평가인 제로벤치 일부 문항에서 43.71점(39.52점), 이미지 디자인을 실제 웹페이지로 바꾸는 비전2웹에서 85.86점(80.20점)을 기록했다. 다만 AI타임스는 세 평가가 이미지·문서 이해에 한정돼 전반적 우위를 뜻하지 않으며, 일반 언어 추론과 코딩 성능은 따로 검증이 필요하다고 짚었다.

외부 평가도 있다. 이미지를 프런트엔드 코드로 바꾸는 디자인아레나 평가에서 엘로 점수 1238점으로 10위에 올랐고, 일대일 비교에서 기업 웹사이트는 약 60%, 개인 포트폴리오는 약 63%의 승률을 보였다.

가격 경쟁력이 강점으로 꼽힌다. 디자인아레나 기준 입력 100만 토큰당 0.30달러, 출력 100만 토큰당 0.90달러로 비슷한 성능대에서 가장 싼 축에 속한다. 앤트그룹은 출시 후 2주간 API를 무료로 제공하며, 이후 공식 가격은 아직 발표하지 않았다. 오픈AI와 앤트로픽의 API 호출 형식을 지원해 기존 연동 코드를 거의 고치지 않고 옮길 수 있다.

시연에서는 여러 전문 에이전트가 2분기 재무 데이터를 분석해 보고서와 6장짜리 이사회 발표 자료, 하이라이트 영상을 만들고 사용자 피드백에 따라 고치는 과정을 보여 줬다. 이미지 디자인을 웹사이트로 만들거나 블렌더를 조작하는 사례도 소개됐다. 현재 API와 온라인 채팅으로 쓸 수 있으며, 이전 링 모델과 달리 가중치 공개 여부는 밝히지 않았다.

## 핵심 포인트

- 총 5600억 매개변수 MoE, 추론 시 약 250억 개만 활성화, 컨텍스트 100만 토큰
- 자체 측정 옴니독벤치 1.5·제로벤치·비전2웹에서 클로드 오퍼스 5보다 높은 점수
- 디자인아레나 이미지→프런트엔드 평가 엘로 1238점, 10위
- 입력 100만 토큰당 0.30달러·출력 0.90달러, 출시 후 2주 무료 API
- 오픈AI·앤트로픽 API 형식 호환, 가중치 공개 여부는 미정
