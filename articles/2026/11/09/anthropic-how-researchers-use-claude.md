# 과학자들은 AI를 어떻게 쓸까…앤트로픽 "데이터 분석이 1위, 가설 생성은 4%"

## 상세 요약

앤트로픽이 5일(현지시간) 공식 블로그에 '과학적 발견을 위한 AI: 연구자들은 클로드를 어떻게 사용하는가' 보고서를 공개했다. 8월 2일부터 9월 30일까지 클로드와 클로드 코드에서 이뤄진 과학 연구 관련 세션 20만 7049건을 분석하고, 과학자 528명을 따로 설문했다. 앤트로픽은 이 연구가 관찰 연구이며 AI가 특정 과학 문제를 풀었다는 사례를 제시하는 것은 아니라고 밝혔다.

결과는 데이터 분석과 글쓰기 쏠림으로 요약된다. 클로드에서는 데이터 분석이 33.7%, 글쓰기·커뮤니케이션이 32.0%로 둘을 합치면 약 66%였다. 클로드 코드에서는 통계 분석 코드 작성, 데이터 정리, 시각화 같은 데이터 분석 비중이 48.1%에 달했다. 반면 아이디어·가설 생성은 클로드 4.2%, 클로드 코드 2.1%에 그쳤다.

연구자들이 중요하게 여기는 일과 AI에 맡기는 일은 엇갈렸다. 설문에서 네 가지 연구 활동에 100점을 나눠 주게 하자 가설 생성이 35.6점으로 가장 높았다. 앤트로픽은 연구자들이 아이디어는 직접 내고 싶어 하거나 가설 작업에서는 AI를 충분히 믿지 않을 수 있다고 해석했다. 가설 관련 작업이 다른 항목으로 분류됐을 가능성도 함께 언급했다.

분야별로는 컴퓨터과학, 수학, 통계학에서 활용이 가장 많았다. 의학과 실험 중심 자연과학은 손으로 하는 실험 비중이 커서 활용이 적었다. AI가 잘하는 상위 20% 작업에서 클로드 사용 비중은 일반 연구 시간 비중의 약 2배, 클로드 코드는 약 4배였다.

과학 데이터베이스와 도구를 연결한 별도 서비스 '클로드 사이언스'에서는 가설 생성 비중이 8%로 일반 클로드의 약 2배였고, 단백질 구조·기능에 관한 가설은 6배 더 자주 나왔다. 다만 이용자가 처음부터 더 어려운 과제를 들고 왔을 수 있어, 도구가 차이를 만들었다고 단정할 수는 없다고 앤트로픽은 덧붙였다.

보고서는 가상의 생산성 시나리오도 제시했다. 현재 수준의 AI가 널리 쓰이면 일부 분야의 연구 산출이 최대 2배가 될 수 있고, 장기적으로 물리적 실험을 뺀 모든 연구 작업이 자동화되면 컴퓨터과학·통계학은 최대 15배, 생물학·화학은 3~4배까지 늘 수 있다는 추정이다. 물리적 실험이 여전히 속도를 제한한다는 단서가 붙었고, 데이터가 개인 요금제 세션에서 나와 전 세계 과학자를 대표하지 않는다는 한계도 명시됐다.

## 핵심 포인트

- 과학 연구 세션 20만 7049건과 과학자 528명 설문을 분석한 관찰 연구
- 클로드는 데이터 분석 33.7%·글쓰기 32.0%, 클로드 코드는 데이터 분석 48.1%

- 클로드 사이언스에서는 가설 생성 비중 8%로 일반 클로드의 약 2배
- 장기 시나리오에서 컴퓨터과학·통계학 산출 최대 15배, 생물학·화학 3~4배 추정
