## 상세 요약

모질라가 11월 24일 파이어폭스 161을 정식 채널에 배포했다. 눈에 띄는 변화는 내장 VPN을 특정 사이트에서만 켜거나 끄는 기능이다.

릴리스 노트는 추가 개인정보 보호나 다른 위치가 필요한 곳에서만 VPN을 쓸 수 있다고 설명한다. 더버지에 따르면 VPN 패널의 'VPN 규칙 관리'에서 사이트마다 '항상 켜기'나 '항상 끄기'를 고르면 된다. 매번 직접 전환할 필요가 없어진다. 더버지는 제목에서 클릭 한 번으로 방문 기록을 지우는 기능도 소개했다.

편의 기능도 늘었다. 현재 탭의 URL을 단축키로 복사할 수 있는데, 기본 키는 지정돼 있지 않아 설정에서 정해야 한다. 탭 그룹은 애플리케이션 메뉴에 표시되고, 테마 페이지에는 프로톤과 OLED 테마 등을 모은 클래식 테마 항목이 생겼다.

웹 플랫폼에서는 CSS random() 함수와 CSS Typed Object Model을 지원한다. 다만 CSSColorValue 같은 색상 값은 아직 지원하지 않는다. 비동기 클립보드 API의 웹 사용자 지정 형식도 같은 출처 페이지에서 쓸 수 있다.

고친 문제로는 파이어폭스 158 이후 일부 WebRTC 화상통화가 저해상도 H.264로 전송되던 현상, Canva Docs에서 일본어·한국어 입력이 첫 글자 뒤 멈추던 현상 등이 있다. macOS 26 이상에서 북마크가 많을 때 스포트라이트를 열면 멈추던 문제도 해결했다. 보안 수정은 권고문 mfsa2026-131로 안내했다.

크롬에서 가져온 방문 기록에는 이제 방문 빈도가 포함돼 자주 간 사이트가 주소창 추천에서 더 위에 나온다.

## 핵심 포인트

- 파이어폭스 161이 내장 VPN의 사이트별 켜기·끄기를 지원한다
- 탭 URL 복사 단축키와 클래식 테마 항목이 추가됐다
- CSS random() 함수와 CSS Typed Object Model을 지원한다
- Canva Docs의 한국어·일본어 입력 중단 문제를 고쳤다
