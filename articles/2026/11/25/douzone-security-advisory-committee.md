# 더존비즈온, 외부 전문가 4명으로 '사이버보안 특별자문위' 출범…지난달 서버 침해사고 뒤 보안 체계 점검

## 상세 요약

더존비즈온이 25일 서울 중구 더존을지타워에서 '사이버보안·정보보호 특별자문위원회' 출범식을 열었다. 외부 보안·법률 전문가의 시각으로 정보보호 관리체계를 점검하려는 조직이다.

기사는 이번 출범을 지난달 발생한 개발 서버와 백업 서버 침해사고 이후의 후속 조치로 풀이했다. 사고의 경위와 피해 규모는 이 기사에 나오지 않는다.

위원은 4명이다. 위원장은 이경호 고려대 정보보호대학원 교수가 맡았다. 김홍선 김·장 법률사무소 고문은 보안 경영과 금융 보안을, 전성학 엔키화이트햇 R&D센터 부사장은 보안 기술과 모의해킹을, 박광배 법무법인 광장 변호사는 개인정보보호와 데이터 규제를 담당한다.

자문 영역은 위협·기술 동향, 보안체계, 정책·규제 동향, 외부 점검 결과 검토의 네 가지다. 사고 예방과 대응·복구 체계가 적정한지 살피고, 외부 보안 진단과 모의해킹 결과를 객관적으로 검증한다. AI 에이전트 악용 같은 신기술 동향을 반영한 개선 과제도 제시한다.

위원회는 월 1회 정례회의를 원칙으로 하고 주요 보안 현안이 생기면 수시로 모인다. 자문 결과는 최고경영자와 이사회, 산하 위원회에 보고하고 이행 경과를 계속 점검한다.

회사 관계자는 사이버 위협이 고도화되면서 선제 대응이 중요해졌다며 자문 의견을 보안 점검과 개선 과제에 반영하겠다고 했다. 자문 결과의 구속력과 위원 임기는 기사에 나오지 않았다.

## 핵심 포인트

- 더존비즈온이 외부 전문가 4명으로 특별자문위원회를 출범했다
- 지난달 개발·백업 서버 침해사고 이후의 후속 조치로 풀이된다
- 위원장은 이경호 고려대 정보보호대학원 교수다
- 월 1회 정례회의를 열고 결과를 최고경영자와 이사회에 보고한다
