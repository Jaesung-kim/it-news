# 할 일 관리 앱 투두이스트 해킹…고객 6% 이메일·비밀번호 해시 유출, 아웃룩 추가 기능도 중단

- 분야: IT 뉴스
- 출처: 테크크런치
- 원문: https://techcrunch.com/2026/11/25/todoist-confirms-6-of-customers-details-were-stolen-in-data-breach/
- 발행일: 2026-11-25

## 상세 요약

할 일 관리 앱 투두이스트(Todoist)가 11월 24일 해커가 운영 시스템에 침입해 고객 데이터를 빼냈다고 밝혔다. 회사는 전체 고객의 약 6%가 영향을 받았으며, 도난당한 자격 증명이 원인이라고 설명했다.

테크크런치에 따르면 공격자는 11월 22일과 23일 탈취한 자격 증명으로 버전 관리 시스템과 소스 코드에 접근했다. 이어 직원 접근 권한 설정을 바꿨고, 한 직원의 업무 계정을 통해 앱의 클라우드 인프라에까지 들어갔다. 회사는 소스 코드가 변경되지는 않았다고 밝혔다.

유출된 정보는 이메일 주소, 비밀번호 해시, 계정 생성일이다. 해커는 특히 예전 해시 방식으로 비밀번호가 저장된 초기 가입자의 자격 증명을 내려받았다. 약 0.001%의 이용자에 대해서는 할 일, 댓글, 첨부 파일 이름을 뒤져 다른 서비스의 자격 증명을 찾으려 했다. 투두이스트 API 토큰과 슬랙 연동 토큰도 빼냈다.

아웃룩용 투두이스트 추가 기능도 공격 경로가 됐다. 메일 읽기 권한을 준 채 연결된 계정에서 해커가 이메일 주소와 첨부 파일 이름을 찾아본 것이다. 투두이스트는 공격 경로를 막고 비밀번호를 초기화했으며, 아웃룩 추가 기능을 중단했다. 내부 접근 권한 구조와 클라우드 환경의 원격 명령 실행 방식도 다시 짰다.

아미르 살리헤펜디치 최고경영자(CEO)는 X에 사과문을 올리고 사고 원인을 더 면밀히 살펴보겠다고 했다. 회사는 피해 이용자에게 통지를 보내 투두이스트 비밀번호를 바꾸고, 같은 비밀번호를 쓰는 다른 서비스도 변경하라고 요청했다. API 토큰을 갱신하고 연동을 다시 연결하며, 댓글 등에 적어 둔 접근 키나 복구 문구, 자격 증명도 폐기하거나 바꾸라고 권고했다.

테크크런치는 이번 사고를 올해 이어진 자격 증명 기반 공격의 흐름 속에 놓고, 우버와 클루(Klue) 사례를 함께 언급했다. 회사의 공식 사고 안내는 투두이스트 도움말 센터에 올라와 있다.

## 핵심 포인트

- 해커가 11월 22~23일 탈취한 자격 증명으로 투두이스트 운영 시스템에 침입했다
- 고객 약 6%의 이메일, 비밀번호 해시, 계정 생성일이 유출됐다
- API 토큰과 슬랙 연동 토큰도 빠져나갔고, 아웃룩 추가 기능을 통한 메일 탐색도 있었다
- 회사는 비밀번호를 초기화하고 아웃룩 추가 기능을 중단했다
- 이용자는 비밀번호와 API 토큰을 바꾸고, 앱에 적어 둔 자격 증명을 폐기해야 한다
