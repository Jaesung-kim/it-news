# 인텔, CPU 설계 체계 재편…립부 탄 "전담 조직 141명, 외부 스타트업도 활용", 아톰 x86 설계 자산 개방

- 원문: https://zdnet.co.kr/view/?no=20261126144946

## 상세 요약

인텔이 외부 스타트업에 CPU 설계 자산을 개방하며 차세대 프로세서 개발 방식을 바꾸고 있다. 지디넷코리아는 이를 립부 탄 최고경영자(CEO)가 추진하는 CPU 아키텍처 개발 체계 재편의 일부로 봤다.

대표 사례는 5월 설립된 미국 반도체 스타트업 로자익랩스다. 인텔은 이 회사에 저전력 아톰 프로세서의 x86 명령어 구조(ISA) 구현 기술과 RTL 설계 자산을 제공했다. 로자익랩스 창업자 아마르지트 길은 립부 탄 CEO와 오랜 투자 파트너이며, 메타가 인수한 리보스의 초기 구성에도 관여했다.

립부 탄 CEO는 투자자 행사 '투모로우X'에서 CPU 경쟁력 회복 계획을 밝혔다. 그는 "CPU 아키텍처 전담 조직을 직접 구성했고 출범 두 달만에 141명 규모로 확대됐다"고 말했다. 내부 전담 조직과 함께 외부 개발팀을 병행해 쓰겠다는 구상이다. CPU의 최우선 과제로는 시장 주도권 회복을 꼽으며 AMD를 따라잡겠다는 의지를 보였다.

탄 CEO는 아마존의 아나푸르나랩스, 메타의 리보스 사례를 들며 '스핀인' 방식의 장점을 설명했다. 스타트업이 빠르게 움직이며 기술을 검증하면, 검증된 기술과 인력을 나중에 본사에 통합하는 방식이다. 기사는 인텔이 로자익랩스의 IP를 다시 사들여 활용할 가능성도 있다고 내다봤다.

기사는 인텔이 2015년까지 쓴 '틱톡' 전략과 2016년부터 내세운 P-A-O 전략을 되짚었다. 2023년 제안한 x86 간소화 규격 x86-S를 2024년 AMD와 자문 그룹을 꾸린 뒤 두 달 만에 접은 일도 언급하며, 레거시를 줄이는 x86 현대화가 다시 추진될 수 있다고 관측했다.

인텔은 CPU 개발부터 공급까지 최대 36개월이 걸린다고 밝혔다. 기사는 이번 재편의 결과물이 이르면 2029년 전후에 나올 것으로 봤다. 다만 로자익랩스의 역할은 아직 불투명하고, 파생 제품 수준에 그칠 수도 있다고 덧붙였다.

## 핵심 포인트

- 인텔이 스타트업 로자익랩스에 아톰용 x86 ISA 구현 기술과 RTL을 제공했다
- 립부 탄 CEO는 CPU 아키텍처 전담 조직을 두 달 만에 141명으로 키웠다고 밝혔다
- 내부 조직과 외부 개발팀을 병행하는 '스핀인' 방식을 추진한다
- CPU 최우선 과제로 시장 주도권 회복과 AMD 추격을 내세웠다
- 개발부터 공급까지 최대 36개월이 걸려 결과물은 2029년 전후로 예상된다
