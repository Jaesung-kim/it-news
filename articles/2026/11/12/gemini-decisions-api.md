# 구글, 선택형 판단 전용 '제미나이 디시전스 API' 출시…응답 0.15~0.25초, 입력 100만 토큰당 10센트

- 분야: AI 뉴스
- 출처: Google(공식 블로그)
- 원문: https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/
- 발행일: 2026-11-11

## 상세 요약

구글이 11일 정해진 선택지 중 하나를 빠르게 고르는 작업에 특화한 '제미나이 디시전스 API(Gemini Decisions API)'를 공개했다. 전용 모델 '제미나이 디시전 1(gemini-decision-1)'이 이 API를 구동한다.

일반 생성형 모델은 답을 토큰 단위로 하나씩 만들어 내지만, 디시전 1은 후보 선택지 전체를 한 번의 연산으로 점수 매기고 확률과 신뢰도를 돌려준다. 구글은 도구 선택, 정책 위반 여부 점검, 질문에 맞는 모델 배정, 문맥 평가처럼 답이 정해진 판단 작업을 주요 용도로 제시했다.

질문 유형은 세 가지다. 조건 충족 확률을 돌려주는 예·아니요형, 2~255개 선택지 중 하나를 고르고 각 선택지의 확률을 함께 주는 객관식, 단계형 기준에 따라 가중 점수를 매기는 점수형이다. 모든 답에는 0~1 사이 신뢰도가 붙어, 애매한 경우를 다른 처리 방식이나 사람 검토로 넘기도록 설계할 수 있다. 텍스트·이미지·오디오·영상·PDF를 최대 25만 6000토큰까지 하나의 입력으로 넣고, 한 요청에 질문을 최대 1000개까지 묶을 수 있다.

구글은 전체 응답 시간이 150~250밀리초이며, 질문 수가 1개에서 100개로 늘어도 지연이 거의 늘지 않는다고 밝혔다. 가격은 입력 100만 토큰당 0.1달러이고 출력 토큰은 무료다. 공통 입력은 요청당 한 번만 과금된다. 자체 벤치마크에서 '제미나이 3.5 플래시 라이트'를 쓰는 것보다 5배 가까이 저렴하고, 비교 모델 중 보정 오차가 가장 낮았다고 주장했다.

구글 내부에서는 이미 쓰이고 있다. 제미나이 노트북은 질문에 맞는 모델 등급을 실시간으로 골라 일상 질의 지연을 최대 40% 줄였고, 구글 검색은 MCP 도구의 악의적 동작을 잡아내는 안전 장치로 활용하고 있다.

API는 구글 AI 스튜디오의 제미나이 API로 제공되며 무료 시험 구간도 있다. 오픈라우터, 랭체인, 버셀, 라이트LLM 등 외부 개발 도구 연동이 순차 적용되고, 구글 클라우드 지원은 곧 추가될 예정이다.

## 핵심 포인트

- 선택지 전체를 한 번에 채점해 확률·신뢰도를 반환하는 판단 전용 모델 '제미나이 디시전 1'
- 예·아니요, 객관식(최대 255개), 점수형 질문 지원, 요청당 최대 1000개 질문
- 응답 150~250밀리초, 입력 100만 토큰당 0.1달러, 출력 무료
- 제미나이 노트북 모델 라우팅, 구글 검색 MCP 안전 점검에 이미 적용
- 구글 AI 스튜디오에서 제공, 구글 클라우드 지원은 예정
