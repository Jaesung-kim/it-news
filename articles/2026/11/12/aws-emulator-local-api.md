# AWS, 자체 로컬 에뮬레이터 'AWS 에뮬레이터' 공개…계정 없이 AWS API 테스트, CC0로 배포

- 분야: IT 뉴스
- 출처: GitHub(aws/aws-emulator), Hacker News, GeekNews
- 원문: https://github.com/aws/aws-emulator
- 발행일: 2026-11-11

## 상세 요약

AWS가 자사 API를 로컬에서 흉내 내는 공식 도구 'AWS 에뮬레이터(AWS Emulator)'를 깃허브에 공개했다. 실제 AWS를 호출하지 않고도 AWS API를 쓰는 소프트웨어를 개발 PC, 개발 서버, CI 환경에서 테스트할 수 있게 해 주는 도구이며, AWS 계정이 없어도 쓸 수 있다. 별도 GUI는 없고 추가 요금도 붙지 않는다. 해커뉴스에서는 500점 넘는 추천과 170여 개 댓글이 달렸다.

사용 방식은 두 가지다. 서버 모드는 리눅스에서 RPM·데비안 패키지로 설치해 실행하고, 윈도와 macOS에서는 도커 컨테이너로 돌린다. AWS CLI나 SDK가 환경 변수로 에뮬레이터 엔드포인트를 바라보게 하면 되며, 기본으로 127.0.0.1:9297에서 자체 서명 인증서 기반 HTTPS를 제공한다. 임베디드 모드는 러스트 개발 의존성으로 추가해 테스트마다 격리된 인스턴스를 프로세스 안에서 띄우는 방식이다.

내부 구조는 러스트로 짜였고 AWS 서비스마다 별도 크레이트를 두는 형태다. 지원 서비스 목록은 README에 따로 정리돼 있지 않으며, 실제 AWS와 얼마나 똑같이 동작하는지는 릴리스마다 공개되는 일치도 점수로 확인하도록 했다. 알려진 미지원·오동작 항목은 저장소의 이슈 디렉터리에서 따로 관리한다.

AWS는 이 도구가 개발과 테스트 전용이라고 못 박았다. 프로덕션 워크로드나 보안 테스트에는 쓰지 말라는 것이다. 소스에서 직접 빌드하려면 x86_64 또는 aarch64 리눅스, 100GB 이상의 디스크, 멀티코어 머신이 필요하고 임베디드 모드도 같은 빌드 비용이 든다.

텔레메트리는 기본으로 켜져 있으며 명령행 옵션, 환경 변수, 설정 파일로 끌 수 있다. 라이선스는 퍼블릭 도메인에 가까운 CC0-1.0이고, 외부 코드를 담은 vendor 디렉터리만 아파치 2.0이다. 다만 저장소는 외부 풀 리퀘스트를 받지 않는다고 밝혔다. 공개 시점 기준 커밋은 2만 9000개를 넘었다.

AWS가 직접 만든 에뮬레이터가 나오면서 개발자들은 실제 클라우드 자원을 쓰지 않고도 테스트마다 격리된 환경을 띄울 수 있는 공식 선택지를 얻게 됐다.

## 핵심 포인트

- AWS가 계정 없이 AWS API를 로컬에서 테스트하는 공식 에뮬레이터를 공개했다
- 리눅스 패키지·도커 기반 서버 모드와 러스트 임베디드 모드를 지원한다
- 개발·테스트 전용이며 프로덕션과 보안 테스트에는 쓰지 말라고 명시했다
- 라이선스는 CC0-1.0이고 텔레메트리는 기본 활성화, 외부 PR은 받지 않는다
- 서비스별 실제 AWS와의 일치도는 릴리스마다 점수로 공개한다

> 배경(편집자 설명): 로컬스택(LocalStack)은 AWS 서비스를 로컬에서 흉내 내는 대표적인 서드파티 오픈소스·상용 도구다.
