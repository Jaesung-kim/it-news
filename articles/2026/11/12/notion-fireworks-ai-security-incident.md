# 노션, AI 공급업체 파이어웍스 보안 사고 공지…워크스페이스 1% 미만 영향, 'ZDR 약속'에도 데이터 남아 있었다

## 상세 요약

노션(Notion)이 자사 AI 기능에 모델을 공급해 온 외부 업체 파이어웍스 AI(Fireworks AI)에서 보안 사고가 발생해 일부 고객 데이터가 영향을 받았다고 공식 공지했다. 파이어웍스가 노션에 사고를 통보했으며, 영향을 받은 곳은 전체 노션 워크스페이스의 1% 미만이다. 정확한 비율은 밝히지 않았고 조사는 진행 중이다.

노출된 데이터는 노션 AI 채팅 기록, 즉 채팅에 입력하거나 모델이 출력한 내용이다. AI 회의록은 채팅 입력으로 쓰지 않았다면 영향이 없다. 노션은 요청을 분류하는 '인사이트(Insights)' 기능이 저장된 노션 AI 요청과 응답을 파이어웍스로 보냈고, 자원 참여 프로그램 'LEAP' 참가자 데이터는 파이어웍스에서 특정 작업용 모델 학습 실험에 쓰였다고 설명했다.

노션은 11월 3일 기준으로 파이어웍스와 연결을 끊고 파이어웍스 시스템에 있던 데이터를 모두 지웠으며, 데이터 전송과 학습 작업도 멈췄다. 인사이트 기능은 꺼졌고 파이어웍스를 통해 제공하던 오픈 웨이트 모델 서비스도 중단됐다.

가장 눈에 띄는 대목은 데이터 무보관(ZDR) 약속이다. 파이어웍스는 계약상 데이터를 보관하지 않기로 했지만, 노션은 "조사 과정에서 우리가 쓴 파이어웍스 엔드포인트에서 데이터가 보관돼 있었다는 사실을 알게 됐다"고 밝혔다. 또 엔터프라이즈 ZDR은 응답 생성을 위한 외부 모델 API 호출에만 적용되며, 데이터 저장이 필요한 채팅 기록과 인사이트에는 적용되지 않는다고 덧붙였다. 노션은 핵심 공급업체 전체를 대상으로 ZDR 준수 여부를 감사하고 있다.

영향을 받은 워크스페이스 소유자는 데스크톱 브라우저 사이드바의 도움말 메뉴에서 '보안 사고 검토' 항목을 열어 영향받은 구성원 목록(이름, 이메일, 사용자 ID)을 CSV로 받을 수 있다. 도메인 인증을 마친 소유자는 영향받은 콘텐츠 목록도 내려받는다. 노션은 해당 데이터를 노출된 것으로 간주하고, 그 기간 노션 AI에 붙여 넣은 비밀번호나 API 키 같은 인증 정보를 바로 교체하라고 권고했다. 연락을 받지 않은 사용자는 지금 당장 할 일이 없다.

이번 사고는 SaaS 기업이 AI 기능을 붙이며 기대는 외부 모델 공급망이 새로운 유출 경로가 될 수 있고, 계약서상 데이터 무보관 약속만으로는 실제 보관 여부를 보장할 수 없다는 점을 보여 준다.

## 핵심 포인트

- 노션 AI 모델 공급업체 파이어웍스 AI의 보안 사고로 워크스페이스 1% 미만이 영향을 받았다
- 노출 대상은 노션 AI 채팅 입력·출력, 인사이트 기능 데이터, LEAP 참가자 데이터다
- 파이어웍스는 계약상 데이터 무보관을 약속했지만 실제로는 데이터가 남아 있었다
- 노션은 11월 3일 파이어웍스 연동을 끊고 데이터를 삭제했으며 공급업체 ZDR 감사에 나섰다
- 영향 고객은 노션 AI에 입력한 비밀번호·API 키를 즉시 교체해야 한다
