# 모질라, 파이어폭스 사용자 2500만 명 측정해 핑거프린팅 방어 강화…"몇 가지 기능만 막아도 추적 크게 약해져"

- 분야: IT 뉴스
- 출처: Mozilla Security Blog, GeekNews
- 원문: https://blog.mozilla.org/security/2026/11/10/open-research-stronger-privacy-making-firefox-users-harder-to-fingerprint/
- 발행일: 2026-11-10

## 상세 요약

브라우저 핑거프린팅은 쿠키 없이 화면 해상도, CPU 코어 수, 그래픽 렌더링 결과 같은 브라우저·기기 정보를 조합해 사용자를 구별하는 추적 기법이다. 모질라는 보안 블로그에서 파이어폭스가 이런 추적 스크립트에 사용자들이 서로 더 비슷하게 보이도록 보호 기능을 강화했다고 밝혔다. 글은 톰 리터, 프레데릭 브라운, 크리스토프 케르슈바우머가 함께 썼다.

근거가 된 연구 논문 「웹 브라우저 핑거프린팅의 대규모 측정과 실제 환경 완화」는 보안 학회 ACM CCS 2026에 채택됐다. 모질라는 핑거프린트 프로, 시그니파이드, 아카마이 등 실제 핑거프린팅 스크립트가 수집하는 값을 흉내 내 측정하고, 이 값들의 조합이 사용자를 얼마나 잘 구별하는지 분석했다.

측정 대상은 파이어폭스 사용자 약 2500만 명이다. 모질라는 기존 데이터 수집 정책에 더해 추가 보호 장치를 뒀다고 설명했다. 요청은 OHTTP 릴레이를 거쳐 릴레이는 IP 주소만, 모질라는 내용만 볼 수 있게 했고, 개별 원격 측정 기록은 몇 달 전에 지우고 집계 결과만 남겨 공개했다.

분석 결과 모질라는 "소수의 브라우저 기능만 보호해도 널리 쓰이는 핑거프린팅 기법을 크게 약화할 수 있다"는 결론을 내렸다. 이에 따라 화면 해상도 API에서는 작업 표시줄이나 독의 크기·위치를 감추고, 프로세서 수는 실제 값 대신 4 또는 8로 알려 주도록 바꿨다. 이미지 렌더링, 웹 오디오, 안드로이드의 수학 연산처럼 기기마다 결과가 달라지던 부분도 더 일관되게 맞췄다.

가장 최근 보호 기능은 파이어폭스 145에 들어갔다. 모질라는 이 변경으로 고유한 핑거프린트를 가진 사용자 수가 줄고, 같은 핑거프린트를 공유하는 사용자 집단은 커졌다고 밝혔다. 작업 표시줄·독 정보 숨김은 모든 브라우징 모드에서 기본으로 켜져 있고, 나머지 보호 기능은 사생활 보호 모드와 '엄격' 추적 방지 모드에 먼저 적용한 뒤 나중에 기본값으로 넓힐 계획이다.

모질라는 한계도 인정했다. 이번 조치가 "핑거프린팅을 불가능하게 만들지는 않으며 추적자들은 분명 적응할 것"이라고 적었다. 연구 결과를 검증할 수 있도록 테스트 도구와 설명 사이트(fingerprinting.study)도 공개했다.

## 핵심 포인트

- 모질라가 파이어폭스 사용자 약 2500만 명의 측정값을 분석한 핑거프린팅 연구를 공개했고, 논문은 ACM CCS 2026에 채택됐다
- 소수의 브라우저 기능만 보호해도 주요 핑거프린팅 기법이 크게 약해진다는 결과가 나왔다
- 작업 표시줄·독 위치를 숨기고 CPU 코어 수를 4 또는 8로만 알려 주는 등 보호 기능이 파이어폭스 145까지 들어갔다
- 일부 기능은 기본 적용, 나머지는 사생활 보호·엄격 모드에 먼저 적용한 뒤 확대할 계획이다
- 모질라는 추적자가 적응할 수 있어 핑거프린팅을 완전히 막지는 못한다고 밝혔다
