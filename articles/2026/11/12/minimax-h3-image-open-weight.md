# 미니맥스, 4K 이미지 약 10초 만에 만드는 오픈웨이트 모델 'H3-이미지' 공개…한국·미국·EU는 기본 라이선스서 제외

- 분야: AI 뉴스
- 출처: AI타임스 (미니맥스 공식 X 게시물 인용)
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217320
- 발행일: 2026-11-12

## 상세 요약

중국 AI 기업 미니맥스(MiniMax)가 11일 이미지 생성 모델 'H3-이미지(H3-Image)'를 공개하고 모델 가중치와 코드를 허깅페이스와 깃허브에 배포했다. 하나의 모델로 이미지 생성과 편집을 함께 처리하며, 최대 16장의 참조 이미지를 활용할 수 있다. 미니맥스 API와 개발 도구 '미니맥스 코드', 영상·이미지 서비스 '하이뤄 AI'에서도 쓸 수 있다.

모델은 지난 7월 내놓은 멀티모달 생성 모델 H3를 바탕으로 한 331억 파라미터 규모의 디퓨전 트랜스포머(DiT)다. 업스케일링 없이 4096×4096(약 1600만 화소) 해상도를 바로 출력하고, 샘플링 단계를 6단계로 줄여 속도를 높였다. 미니맥스는 공식 게시물에서 "10초 만에 4K 이미지 생성"을 내세웠다.

미니맥스가 제시한 비교표에 따르면 4K 기준 생성 시간은 표준 모드 16초, 고속 모드 10.3초로, 구글 '나노 바나나 2.1'의 48~64초보다 크게 빠르다. 회사는 주요 상용 모델보다 최대 5배 빠르다고 주장했다. 다만 1K 해상도에서는 표준 모드가 10.6초로 'GPT 이미지 2.6' 중간 모드(9초)보다 느려, 낮은 해상도에서는 속도 우위가 뚜렷하지 않다.

API 가격은 장당 1K 약 0.022달러, 2K 0.023달러, 4K 0.069달러, 4K 고속 모드 약 0.13달러다. 17일까지는 4K 이상 요청에 50% 할인을 적용한다. 미니맥스는 할인 전 가격도 주요 경쟁 모델의 50~70% 수준이라고 밝혔다.

오픈웨이트이지만 사용 조건은 까다롭다. 한국과 미국, 영국, EU는 기본 커뮤니티 라이선스 적용 대상에서 빠져 있어 이 지역에서 쓰거나 배포하려면 별도 허가가 필요하다. 그 밖의 지역에서도 연 매출 100만 달러를 넘는 기업이나 외부 이용자에게 서비스를 제공하는 경우 미니맥스의 사전 서면 승인을 받아야 한다. 프롬프트 반영도나 이미지 품질에 대한 독립적인 검증 결과는 아직 나오지 않았다.

## 핵심 포인트

- 331억 파라미터 DiT 기반, 생성·편집 통합에 참조 이미지 최대 16장 지원
- 업스케일링 없이 4K 직접 출력, 고속 모드 10.3초(미니맥스 자체 비교)
- 1K에서는 GPT 이미지 2.6보다 느려 해상도별 속도 우위는 제한적
- 4K 장당 0.069달러, 17일까지 4K 이상 50% 할인
- 한국·미국·영국·EU는 기본 라이선스 제외, 별도 허가 필요
