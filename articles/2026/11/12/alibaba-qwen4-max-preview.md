# 알리바바, '큐원4' 첫 모델 '큐원4 맥스 프리뷰' 공개…100만 토큰 컨텍스트, 가중치·벤치마크는 비공개

## 상세 요약

알리바바가 차세대 모델 제품군 '큐원4(Qwen4)'의 첫 모델인 '큐원4 맥스 프리뷰(Qwen4-Max-Preview)'를 11일(현지시간) 발표했다. 최대 100만 토큰의 컨텍스트를 지원하고 코딩과 AI 에이전트 기능을 강화한 것이 특징이다.

다만 공개 방식은 제한적이다. 알리바바는 모델 가중치는 물론 벤치마크 결과나 기술 보고서도 내놓지 않았고, 자사 서비스에 먼저 적용했다. 큐원 시리즈가 그동안 오픈웨이트 공개로 존재감을 키워 온 것과 달리, 이번에는 폐쇄형 서비스 형태로 먼저 선보인 셈이다. 연구진은 이 모델이 "더 깊은 지식과 풍부한 세계 이해, 강력한 코딩 및 에이전트 기능을 제공한다"고 소개했다.

사양을 보면 컨텍스트는 100만 토큰이고, 추론 과정과 최종 답변을 합친 최대 출력은 39만 3216토큰이다. 추론 기능은 기본으로 켜져 있으며 강도를 조절할 수 있다. 텍스트·이미지·영상을 입력으로 받고, 웹 검색과 함수 호출, 내장 도구, JSON 스키마 기반 구조화 출력을 지원한다. 오픈AI와 앤트로픽 API 형식과도 호환된다.

이용 경로는 구독형 API 서비스 '토큰 플랜(Token Plan)'과 큐원워크(QwenWork), 코더(Qoder), 큐원 앱, 큐원스튜디오다. API는 토큰 플랜 구독자만 쓸 수 있고 사용량 기반 종량제는 지원하지 않는다.

프리뷰 기간은 11일부터 25일까지이며 이후 서비스에서 내려간다. 별도 API 가격이나 정식 출시 일정, 구체적인 성능 지표는 아직 공개되지 않아, 실제 경쟁력은 정식 버전이 나온 뒤에야 판단할 수 있을 전망이다.

- 최대 출력 39만 3216토큰, 텍스트·이미지·영상 입력, 오픈AI·앤트로픽 API 호환
