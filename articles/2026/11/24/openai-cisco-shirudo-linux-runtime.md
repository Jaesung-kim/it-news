# 오픈AI·시스코, 패치 전 리눅스 시스템 지키는 오픈소스 런타임 '시루도' 공개…재시작 없이 보호 장치 적용

- 분야: AI 뉴스
- 출처: OpenAI 공식 블로그
- 원문 링크: https://openai.com/index/introducing-shirudo
- 발행일: 2026-11-23

## 상세 요약

오픈AI와 시스코가 11월 23일 실행 중인 리눅스 시스템을 보호하는 오픈소스 런타임 '시루도(Shirudo)'를 공개했다. 이름은 방패를 뜻하는 일본어에서 왔다. 패치나 재시작을 기다리지 않고 취약점을 노린 동작을 막는 것이 목적이다.

오픈AI는 패치를 시험하고 배포하는 데 며칠에서 몇 주가 걸릴 수 있다고 설명했다. 공격과 정상 요청이 같은 리눅스 연산을 쓰는 경우도 있어, 해당 연산을 통째로 막으면 서비스가 멈출 수 있다. 시루도에서는 보호 장치인 '실드'가 공격은 막고 정상 요청은 통과시키는지 먼저 시험하고, 운영자가 승인하면 서비스가 돌아가는 중에 배포한다.

기술 기반은 운영체제의 특정 지점에서 작은 프로그램을 실행하는 eBPF다. 실드는 취약한 코드 경로를 막으며, 적용 전에 애플리케이션에 미칠 영향을 살펴볼 수 있다. AI 에이전트가 취약점을 조사하고 실드를 만들어 실제 공격과 작업 부하로 검증할 수 있지만, 배포 여부는 보안팀이 정한다.

배포 과정의 안전장치도 마련했다. 실드는 암호학적으로 서명되고 로드 전에 검증되며, eBPF 검증기와 커널 보안 제어가 무단 변경을 제한한다. 하드웨어 보안 모듈인 TPM을 활용해 보호 장치가 올라가고 제거된 기록도 검증 가능한 형태로 남긴다.

오픈AI는 통제된 시험에서 코덱스가 만든 실드로 Java4Shell 공격을 막았다고 밝혔다. 자바의 Base64 디코더에 입력 검사를 더하는 실드를 실행 중인 엘라스틱서치 프로세스에 직접 연결했고, 공격 입력은 거부되면서 서비스는 계속 돌아갔다.

그레그 브록먼 오픈AI 사장은 버그를 찾았다고 모든 시스템을 이튿날 바로 패치할 수 있는 것은 아니라며, 많은 팀이 같은 소프트웨어에 의존하는 만큼 이런 도구는 공개적으로 만드는 것이 맞다는 취지로 말했다.

시루도는 깃허브에서 BSD 2-Clause 라이선스로 공개됐고, BPF 프로그램에는 BSD와 GPL 이중 라이선스가 적용된다. 두 회사는 검증된 실드를 취약점 공개와 함께 제공해 영구 패치가 나오기 전까지 임시 보호 수단으로 쓰이게 한다는 목표를 제시했다. 기술 심화 웹 세미나는 12월 15일에 열린다.

## 핵심 포인트

- 오픈AI와 시스코가 실행 중인 리눅스를 보호하는 오픈소스 런타임 시루도를 공개했다.
- eBPF 기반 실드를 재시작 없이 적용해 취약한 코드 경로를 막는다.
- AI 에이전트가 실드를 만들고 검증하되 배포 결정은 보안팀이 한다.
- 시험에서 코덱스가 만든 실드가 엘라스틱서치 대상 Java4Shell 공격을 막았다.
- BSD 2-Clause 라이선스로 깃허브에 공개됐다.
