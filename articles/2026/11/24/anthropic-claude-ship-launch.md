# 앤트로픽, 코드 리뷰·수정·승인까지 맡는 에이전트 묶음 '클로드 십' 출시…팀이 정한 정책 파일로 자동 승인

## 상세 요약

최근 상장한 앤트로픽이 11월 23일(현지시간) 코드 변경의 리뷰, 수정, 승인을 자동화하는 AI 에이전트 묶음 '클로드 십(Claude Ship)'을 공개했다. AI가 작성한 코드가 빠르게 늘면서, 사람이 모든 변경을 일일이 검토하고 승인하는 과정이 새로운 병목이 됐다는 문제의식에서 나온 제품이다.

클로드 십은 세 가지 기능으로 구성된다. 이미 정식 출시된 '코드 리뷰(Code Review)'에 더해, 베타로 나온 'PR 스튜어드(PR Steward)'는 실패한 CI 검사, 병합 충돌, 코드 리뷰 지적 사항을 스스로 처리한다. 푸시할 때마다 무엇을 바꿨는지, 어떻게 되돌릴 수 있는지를 댓글로 남긴다.

역시 베타인 '클로드 승인(Claude Approvals)'은 팀이 저장소 안에 파일로 작성한 승인 정책에 따라 변경을 승인한다. 정책은 자연어로 쓸 수 있고, 코드 리뷰 결과나 앤트로픽 자체 분류기 신호를 판단 근거로 삼을 수 있다.

앤트로픽은 베타 단계인 만큼 처음에는 승인 기능을 '관찰 전용' 모드로 돌려 보라고 권했다. 저장소 하나부터 시작하고 월 사용 한도를 정할 수 있으며, 클로드 십이 어디서 돌지, 리뷰 강도를 빠름·표준·심층 중 무엇으로 할지, 어떤 변경을 사람에게 넘길지는 팀이 직접 정한다.

회사는 "대부분 팀은 모든 변경을 사람이 승인하길 원하고, 사람이 모든 줄을 쓸 때는 그게 어렵지 않다"고 설명했다. 또 클로드 코드 팀에서는 이미 클로드가 대부분의 코드를 작성하고 있어, PR 이후 단계도 그만큼 빨라지길 원했다고 밝혔다.

클로드 십은 깃허브 저장소를 쓰는 클로드 팀·엔터프라이즈 요금제 고객에게 순차 배포된다. 요금제 외의 별도 가격 정보는 공개되지 않았다.

## 핵심 포인트

- 앤트로픽이 코드 리뷰·수정·승인을 자동화하는 에이전트 묶음 클로드 십을 내놨다.
- PR 스튜어드는 CI 실패·병합 충돌·리뷰 지적을 스스로 고치고 되돌리는 법을 남긴다.
- 클로드 승인은 저장소에 자연어로 작성한 정책 파일에 따라 변경을 승인한다.
- 앤트로픽은 처음엔 관찰 전용 모드와 월 사용 한도로 시작할 것을 권했다.
- 깃허브를 쓰는 팀·엔터프라이즈 요금제부터 배포된다.
