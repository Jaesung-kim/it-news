# 바이두, AI가 스스로 실험하는 자동 연구 시스템 '어니 이볼브' 공개…개발 중 모델 추론 속도 6.24배

- 분야: AI 뉴스
- 출처: AI타임스
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217240
- 발행일: 2026-11-10

## 상세 요약

중국 바이두가 9일(현지시간) 공식 블로그를 통해 AI 자동 연구 시스템 '어니 이볼브(ERNIE Evolve)'를 발표했다. AI가 연구 방향을 고르고 코드를 고친 뒤 실험과 평가를 반복하며 성능 개선 방법을 찾는 시스템이다. 바이두는 이를 실제 AI 연구개발에 재귀적 자기 개선(RSI)을 적용하는 첫걸음이라고 소개했다.

구조는 여러 역할로 나뉜다. '디렉터'가 기존 논문·코드·과거 실험 결과를 바탕으로 연구 목표를 정하고, 여러 AI 에이전트가 각자 개선안을 찾아 병렬로 실험한다. '셀렉터'가 다음 개선 대상을 고르면 '실행기'가 코드를 수정해 테스트한다. '평가기'와 '리뷰어'는 성능이 실제로 좋아졌는지 확인하면서 과적합이나 평가 허점을 노린 편법을 걸러낸다. 성공과 실패 기록은 모두 '경험 은행'에 쌓여 다음 연구 방향을 정하는 데 쓰인다.

바이두는 학습 알고리즘, 학습 속도, GPU 코드 최적화를 다루는 공개 벤치마크 3종에서 4개 지표 중 3개의 기존 최고 기록을 넘었다고 밝혔다. 나노챗 오토리서치에서는 0.8763(낮을수록 좋음)으로 기존 0.8878을 앞섰고, 나노GPT 스피드런에서는 목표 성능 도달 시간을 39.9초에서 38.9초로 줄였다. GPU 커널 최적화 평가인 SOL-엑섹벤치에서는 텐센트 '하이라-1.0' 등보다 높았지만 전체 최고 기록에는 못 미쳤다. 모두 바이두 자체 평가다.

실제 개발에도 적용했다. 개발 중인 '어니-5.5-플래시'를 쿤룬신 P800 칩에서 돌리는 저지연 작업에서, 네 차례의 자동 연구로 텍스트 생성 속도를 기준 대비 6.24배로 끌어올렸다. 약 168시간의 반복 실험 결과이며, 모델이나 배포 환경을 바꾸지 않고 쓰이지 않던 최적화 기능을 켜고 연산·데이터 전송의 비효율을 줄인 결과다. 수정된 코드는 정확도 검증도 통과했다.

GPU 환경에서는 같은 입력에 같은 출력을 내야 하는 추론 작업의 처리량을 약 3일 만에 33.7% 높였고, 별도 추론 최적화에서는 정확도를 유지하면서 생성 속도를 14.9% 개선했다.

한계도 분명하다. 기사는 "완전한 RSI를 구현한 것은 아니다"라고 짚었다. 사람이 정한 목표와 평가 기준 안에서 작동하고, 성과도 학습 알고리즘과 추론 소프트웨어 최적화에 집중돼 있다. 전체 시스템은 공개하지 않았고, 공개 벤치마크의 최적화 코드와 실험 기록만 깃허브에 올렸다.

바이두는 앞으로 모델 학습 시스템 전반으로 자동화를 넓히고, 궁극적으로는 AI가 연구 가설과 실험 방법, 평가 기준까지 세우도록 할 계획이다. 연구 목표와 권한은 사람이 통제하고 필요하면 시스템을 멈출 수 있게 하겠다고 밝혔다.

## 핵심 포인트

- 디렉터·에이전트·평가기·경험 은행으로 구성된 AI 자동 연구 시스템
- 공개 벤치마크 4개 지표 중 3개에서 기존 최고 기록 경신(자체 평가)
- 개발 중인 어니-5.5-플래시의 쿤룬신 칩 추론 속도 6.24배 개선
- 사람이 정한 목표 안에서 작동해 완전한 RSI는 아니라고 명시
- 전체 시스템은 비공개, 벤치마크 코드와 실험 기록만 깃허브 공개
