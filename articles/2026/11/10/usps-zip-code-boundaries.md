## 상세 요약

미국 우정청(USPS)이 공식 우편번호(ZIP Code) 경계 폴리곤 데이터 'USPS ZIP Code Boundaries'를 제공한다. 지도·위치 데이터를 다루는 개발자 커뮤니티 해커뉴스에서 큰 관심을 모았다.

이 데이터는 USPS가 가진 배달 주소와 위치 정보로 만든 미국 전역 우편번호 지도다. 배달 분포가 바뀌면 경계도 달라질 수 있으며, 새로 생기거나 바뀐 배달 위치를 반영한다.

상품은 사내용(Internal), 자회사·협력사에 제한 배포하는 기업용(Enterprise), 제한적 출판용(Publication) 세 가지이며, 모두 1년에 네 번 분기별로 갱신된다.

USPS는 지도 제작, 우편 발송, 마케팅, 보험, 부동산, 물류, 내비게이션, 운송 등을 활용 분야로 제시했다. 배송 경로를 짤 때 우편번호를 배달 위치 묶음의 대용 지표로 쓸 수 있다고도 설명했다.

안내 페이지에는 브리핑 자료, 기술 가이드, 샘플 파일, GeoJSON 샘플 파일, 라이선스 계약서, 주문서가 2026년 9월 18일 날짜로 올라와 있다. 가격과 구체적인 라이선스 조건은 안내 페이지 본문에 나오지 않는다.

USPS는 공식 경계 폴리곤을 지리 데이터 결합에 쓰거나, 경계 변경에 맞춰 기존 우편번호 데이터를 고치는 데 활용할 수 있다고 안내했다.

> 배경(편집자 설명): 우편번호는 본래 배달 경로의 묶음이라 공식 면 경계가 없었고, 미국 인구조사국은 이를 근사한 ZCTA(ZIP Code Tabulation Areas)라는 통계 구역을 별도로 만들어 배포해 왔다.

## 핵심 포인트

- USPS가 배달 주소·위치 정보 기반의 공식 우편번호 경계 폴리곤을 제공한다
- 사내용·기업용·출판용 세 가지 상품이 모두 분기마다 갱신된다
- 기술 가이드, GeoJSON 샘플, 라이선스 계약서, 주문서를 공개했다
- 가격과 세부 라이선스 조건은 안내 페이지에 나와 있지 않다
