# 유튜브, 2027년부터 빌보드 차트에 스트리밍 데이터 다시 제공…광고 기반 무료 재생 가중치 높여 갈등 봉합

- 분야: IT 뉴스
- 출처: TechCrunch
- 원문: https://techcrunch.com/2026/11/09/youtube-streaming-data-returns-to-billboard-charts-ending-major-disagreement/
- 발행일: 2026-11-09

## 상세 요약

유튜브가 2027년부터 빌보드에 스트리밍 데이터를 다시 제공한다. 빌보드가 차트 산정 공식을 바꿔 광고를 보고 무료로 듣는 스트리밍에 더 큰 비중을 주기로 하면서 약 1년간 이어진 갈등이 마무리됐다. 유튜브는 11월 9일 공식 블로그로 이를 발표했다.

갈등은 2025년 12월 유튜브가 빌보드에 데이터 제공을 중단하겠다고 밝히면서 시작됐다. 유튜브는 기존 공식이 유료 구독에 유리하고, 광고를 보며 무료로 듣는 팬을 제대로 반영하지 못한다고 주장했다.

당시 라이어 코언 유튜브 글로벌 음악 총괄은 블로그 글에서 빌보드가 "낡은 공식"을 쓴다고 비판했다. 그는 스트리밍이 미국 녹음 음악 매출의 84%를 차지한다는 점도 들었다.

기존 공식에서는 유료 스트리밍 1000회가 광고 기반 스트리밍 2500회와 같게 계산됐다. 새 앨범 소비 단위 공식에서는 유료 1000회가 광고 기반 1500회와 같다. 유료 재생의 가중치가 여전히 더 높지만, 무료 재생이 순위에 미치는 영향은 크게 늘었다.

TechCrunch는 이번 복귀가 독립 음악가나 해외 팬층이 두터운 아티스트에게 특히 중요할 수 있다고 봤다. 유튜브의 뮤직비디오, 라이브 공연, 가사 영상도 다시 빌보드 성적에 반영된다.

## 핵심 포인트

- 유튜브가 2027년부터 빌보드에 스트리밍 데이터를 다시 제공한다
- 2025년 12월 유튜브가 산정 공식에 반발해 데이터 제공을 끊으면서 갈등이 시작됐다
- 유료 1000회 대 광고 기반 2500회였던 환산 비율이 1000회 대 1500회로 바뀐다
- 뮤직비디오·라이브·가사 영상이 다시 빌보드 성적에 반영된다
