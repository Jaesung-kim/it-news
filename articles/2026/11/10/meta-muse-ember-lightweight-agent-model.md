# 메타, 에이전트 실행용 경량 모델 '뮤즈 엠버' 공개…입력 100만 토큰당 10센트

- 분야: AI 뉴스
- 출처: TechCrunch
- 원문: https://techcrunch.com/2026/11/09/meta-releases-muse-ember-a-new-lightweight-model-for-agent-execution/
- 발행일: 2026-11-09

## 상세 요약

메타 슈퍼인텔리전스 랩스가 9일(현지시간) 경량 모델 '뮤즈 엠버(Muse Ember)'를 공개했다. TechCrunch는 이 모델을 메타 연구소가 지금까지 내놓은 모델 가운데 가장 가볍고 비용 효율이 높은 모델이라고 소개했다. 가격은 입력 100만 토큰당 10센트로, 경쟁사 프런티어 경량 모델보다 크게 싸다.

메타는 엠버를 에이전트가 하루 종일 반복하는 작업용으로 설계했다고 설명했다. 도구 호출, 코딩 하위 작업, 라우팅, 정보 추출, 긴 문서 분석 같은 일이다. 텍스트·이미지·오디오를 모두 다루는 멀티모달 모델이어서, 스크린샷·차트·스캔 문서나 음성 메모·회의 녹음·영상을 별도 모델 없이 처리할 수 있다고 한다.

엠버는 큰 모델과 짝을 이루는 구조를 전제로 한다. 메타가 든 예시는 고객 지원 업무다. 프런티어 모델 '뮤즈 원더'가 사례 처리 방침과 규칙을 세우면, 엠버가 이를 수만 건의 실제 사례에 적용한다. 메타는 이를 "뮤즈 원더가 계획하고, 뮤즈 엠버가 물량을 처리한다"고 표현했다.

성능 비교에서 메타는 아티피셜 애널리시스의 종합 지능 지수 대비 과제당 비용을 내세웠다. 이 기준에서 엠버가 앤트로픽의 하이쿠, 오픈AI의 루나보다 싸면서 더 똑똑하다는 주장이다. 오픈소스 경쟁 모델인 딥시크 V4.1 플래시, GLM 5.3 플래시와도 비용 면에서 경쟁할 만하다고 밝혔다. 다만 기사에는 구체적인 점수가 제시되지 않았고, 출력 토큰 가격과 컨텍스트 길이, 제공 경로도 나오지 않았다.

엠버는 뮤즈 브랜드의 네 번째 모델이다. 메타는 4월 중형 모델 '스파크', 8월 그 오픈소스 쌍둥이 '글리머', 10월 프런티어 모델 '원더'를 차례로 내놨고, 9월에는 소비자용 '뮤즈 에이전트'를 출시했다. 이번 경량 모델 추가로 대형 모델이 계획하고 소형 모델이 대량 실행을 맡는 다층 구성을 갖추게 됐다.

## 핵심 포인트

- 메타 슈퍼인텔리전스 랩스의 가장 가볍고 저렴한 모델, 입력 100만 토큰당 0.10달러
- 도구 호출·라우팅·추출·긴 문서 분석 등 에이전트 반복 작업에 초점
- 텍스트·이미지·오디오를 다루는 멀티모달 모델
- 원더가 계획하고 엠버가 대량 실행하는 조합을 제시
- 하이쿠·루나보다 비용 대비 성능이 낫다는 주장, 구체적 점수·출력 가격은 미공개
