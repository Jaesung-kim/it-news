# LG AI연구원, 'K-엑사원 2.5' API 무료 전면 개방…"내년 1월 프런티어급 모델 완성 목표"

- 분야: AI 뉴스
- 출처: AI타임스
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217175
- 발행일: 2026-11-09

## 상세 요약

LG AI연구원이 9일부터 독자 AI 파운데이션 모델 'K-엑사원 2.5'의 API를 누구나 무료로 쓸 수 있도록 전면 개방했다. 서울 코엑스에서 열린 '엔비디아 AI 데이 서울 2026'에서 발표한 내용으로, 개발자·스타트업·기업·연구기관 누구나 API 키만 받으면 비용 없이 서비스 개발과 연구에 활용할 수 있다.

모델은 LG가 자체 서버에서 운영하므로 이용자가 별도 인프라를 갖출 필요가 없다. AI타임스는 오픈 모델 대부분이 가중치를 내려받는 방식으로 제공되는 것과 달리 서버 호스팅으로 직접 제공한다는 점이 이례적이라고 평가했다. 개방 기간에 대해 LG 측은 "명시적으로 정하지 않았다"고 밝혔고, 사용량 한도도 공개되지 않았다. 무료 개방에 따른 시스템 부하를 인정하며 더 많은 이용자가 써볼 수 있도록 적절한 가이드라인을 마련하겠다고 했다.

K-엑사원 2.5는 독파모 사업 2단계 모델에 추가 학습을 더한 기술 검증용 모델이다. LG는 오픈 데이터셋 24개 지표 종합 점수가 2단계 모델 대비 8주 만에 70% 넘게 올랐다고 밝혔다. 에이전트 관련 4개 지표에서는 딥시크 V4.1 플래시, GLM-5.3(Max)와 비슷한 수준이라고 설명했다.

구체적으로 오토메이션 벤치 74.6점(딥시크 74.9, GLM 71.6), 브라우즈컴프 78.0점(딥시크 75.8, GLM 79.0), SWE-벤치 프로 59.2점(딥시크 58.4, GLM 64.0)을 기록했다. 4개 지표 중 딥시크보다는 2개에서 앞섰고 GLM에는 3개에서 뒤졌다. 모두 LG 자체 측정 결과다.

LG는 추론 효율을 높이기 위해 엔비디아 다이나모 추론 서버 도입을 검토하고 있으며, 2.5에서 얻은 데이터 설계·사후학습·강화학습 노하우를 3단계 모델에 반영할 계획이다. 임우형 공동 연구원장은 "내년 1월까지 프론티어급 성능의 엑사원 모델을 완성하는 데 집중하겠다"고 말했다. 독파모 3단계에는 SK텔레콤, 업스테이지, LG AI연구원이 참여하고 있으며, 내년 2월 단계 평가에서 두 팀이 선정될 예정이다.

## 핵심 포인트

- K-엑사원 2.5 API를 9일부터 누구나 무료로 이용 가능, LG 자체 서버에서 호스팅
- 개방 기간과 사용량 한도는 정해지지 않음
- 24개 지표 종합 점수가 2단계 모델 대비 8주 만에 70% 이상 상승(자체 측정)
- 에이전트 지표에서 딥시크 V4.1 플래시·GLM-5.3과 비슷한 수준
- 내년 1월 프런티어급 엑사원 완성 목표, 2월 독파모 단계 평가 예정
