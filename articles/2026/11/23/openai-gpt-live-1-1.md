# 오픈AI, 실시간 음성 모델 'GPT-라이브-1.1' API 출시…유휴 시간 '대기 모드' 분당 0.02달러로 활성 대비 60% 저렴

- 분야: AI 뉴스
- 출처: AI타임스
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217655
- 발행일: 2026-11-22

## 상세 요약

오픈AI가 11월 19일(현지시간) 개발자 커뮤니티를 통해 음성 에이전트용 실시간 음성 모델 'GPT-라이브-1.1(GPT-Live-1.1)'을 API로 내놓았다. 이 모델은 10월 15일부터 챗GPT 플러스·프로의 음성 기능에 먼저 쓰여 왔고, 이번에 개발자들도 자체 서비스에 붙일 수 있게 됐다.

기존 GPT-라이브-1보다 여러 언어에서 억양이 더 자연스럽고 일관되며, 이름이나 인증번호처럼 글자·숫자를 정확히 다뤄야 하는 정보 처리 능력이 나아졌다. 지시 수행과 작업 완료 능력도 개선됐다.

듣기와 말하기를 동시에 하는 전이중 방식이어서 사용자가 답변 도중 끼어들거나 추가 질문을 할 수 있다. 복잡한 추론이나 도구 사용은 개발자가 고른 백엔드 모델에 맡겨, 음성 대화가 끊기지 않도록 했다.

새로 추가된 '대기(Standby)' 설정은 운영 비용을 겨냥했다. 개발자가 5~60초 사이로 유휴 시간을 정하면, 그동안 말소리가 감지되지 않을 때 모델 추론을 멈춘다. WebRTC 연결과 대화 기록은 유지되고 사용자가 다시 말하면 자동으로 대화가 이어지며, 재개 직후 첫 응답은 평소보다 느릴 수 있다.

요금은 대기 상태 분당 0.02달러, 활성 상태 분당 0.05달러로, 대기 요금이 활성 요금보다 60% 싸다. 대기 기능은 GPT-라이브-1과 1.1 모두에서 쓸 수 있고, 백엔드 모델과 도구 사용 비용은 따로 청구된다. 이용은 `v1/live/sessions` 엔드포인트로 하며 음성과 텍스트 입출력을 지원한다.

오픈AI는 다국어 음성 상담, 이름과 인증번호를 정확히 받아야 하는 고객 지원, 대기 시간이 긴 전화 상담 에이전트 등을 주요 활용 사례로 제시했다. 원문에는 성능 벤치마크 수치는 실리지 않았다.

## 핵심 포인트

- 오픈AI가 실시간 음성 모델 GPT-라이브-1.1을 API로 출시했다.
- 다국어 억양과 이름·인증번호 같은 글자·숫자 처리 정확도가 개선됐다.
- 무음이 이어지면 추론을 멈추는 대기 모드를 5~60초 단위로 설정할 수 있다.
- 대기 요금은 분당 0.02달러로 활성 요금 0.05달러보다 60% 싸다.
- 복잡한 추론과 도구 사용은 백엔드 모델에 맡겨 대화 흐름을 유지한다.
