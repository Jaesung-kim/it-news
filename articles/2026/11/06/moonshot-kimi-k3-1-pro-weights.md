# 문샷 AI, 2조 8000억 파라미터 '키미 K3.1 프로' 가중치 공개…딥시크 희소 어텐션 결합

- 분야: AI 뉴스
- 출처: AI타임스
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217051
- 모델 저장소: https://huggingface.co/moonshotai/Kimi-K3.1-Pro
- 발행일: 2026-11-04(현지시간 공개), 2026-11-05(AI타임스)

## 상세 요약

중국 문샷 AI가 4일(현지시간) 허깅페이스에 '키미 K3.1 프로'의 가중치를 배포했다. 지난달 모델을 내놓으면서 예고한 일정에 따른 조치로, 개발자는 이제 모델을 자체 인프라에서 돌리고 수정할 수 있다. 문샷의 API를 쓰는 방법도 그대로 남아 있다.

규모가 눈에 띈다. 저장소 용량은 약 1.56TB로 가중치 파일만 96개로 나뉘어 있다. 전문가 혼합(MoE) 구조로 전체 파라미터는 2조 8000억 개이며, 추론 때 실제로 활성화되는 것은 1040억 개다. 텍스트와 이미지를 입력받고 컨텍스트는 약 100만 토큰까지 지원한다.

구조에서 주목할 점은 경쟁사 기술의 채택이다. 전체 93개 층 가운데 69개는 KDA, 24개는 게이트 방식의 딥시크 희소 어텐션(DSA)으로 구성됐다. DSA는 키미 K3의 전체 어텐션 층을 대체한 것으로, 주목할 토큰을 골라 처리해 긴 문맥에서 효율을 높인다. 가중치는 MXFP4, 활성화 값은 MXFP8 저정밀도 형식을 쓰며 양자화 인지 학습을 적용했다. 권장 추론 엔진은 vLLM, SGLang, 토큰스피드다.

주요 용도로는 코딩, 3D 제작, 금융 조사 같은 에이전트 작업을 꼽았다. 안전 측면에서는 앞선 출시 발표 때 학습 중간 데이터와 강화학습 과제에서 사이버 보안 콘텐츠를 걸러, 일반 코딩 능력은 유지하면서 공격 코드 작성 능력을 낮췄다고 밝혔다.

완전한 자유 이용은 아니다. 문샷 자체 라이선스는 사용, 수정, 파인튜닝, 재배포, 상업적 이용을 허용하지만 조건을 달았다. 모델 제공자와 계열사의 12개월 연속 매출이 2000만 달러를 넘으면 상업적 이용 전에 별도 계약을 맺어야 한다. 월간 활성 이용자가 1억 명을 넘거나 월 매출이 2000만 달러를 넘는 상용 제품은 모델 이름을 표시해야 한다. 내부 이용과 문샷 공식 제품, 인증된 추론 파트너를 통한 이용은 두 의무에서 제외된다.

## 핵심 포인트

- 허깅페이스에 약 1.56TB, 96개 파일로 가중치 공개
- 전체 2조 8000억 파라미터, 추론 시 활성 1040억 개의 MoE 구조
- 93개 층 중 24개에 딥시크 희소 어텐션을 적용해 긴 문맥 효율 개선
- 학습 과정에서 사이버 보안 콘텐츠를 걸러 공격 코드 작성 능력을 낮췄다고 설명
- 자체 라이선스로 상업 이용을 허용하되 일정 규모 이상은 별도 계약이나 모델명 표시 필요
