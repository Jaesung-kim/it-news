# 오픈AI, 코드 저장 스타트업 피에르 인수…코덱스로 개발 전 과정 통합 노린다

## 상세 요약

오픈AI가 4일(현지시간) 코드 저장·버전 관리 기술을 가진 스타트업 피에르 컴퓨터 컴퍼니를 인수한다고 발표했다. 코딩 에이전트 코덱스에 코드 저장과 변경 이력 관리를 붙여, 개발자가 AI와 함께 소프트웨어를 만드는 전 과정을 한 환경에서 처리하게 하려는 것이다. 인수 금액은 공개되지 않았고, 거래는 규제 당국 승인을 거쳐 마무리된다.

피에르의 대표 제품은 깃(Git) 위에서 애플리케이션 코드를 저장하고 변경 이력을 추적하는 '코드 스토리지'다. 오픈소스 개발 도구도 여럿 만들었으며, 코덱스 앱은 이미 파일 탐색과 변경 검토에 피에르의 오픈소스 라이브러리 '트리스'와 '디프스'를 쓰고 있다.

기존 이용자에 대한 약속도 나왔다. 피에르의 오픈소스 프로젝트는 인수 후에도 오픈소스로 유지되고, 코드 스토리지 고객은 코덱스 통합이 진행되는 동안 기존 서비스를 계속 쓸 수 있다.

오픈AI는 이미 내부적으로 코드 관리 인프라를 키워 왔다. AI타임스에 따르면 오픈AI는 2일 공식 블로그에서 자체 소스 관리 시스템 '판도'의 성과를 공개했다. 깃 사용 방식을 바꾸지 않고 여러 브랜치의 동시 작업을 처리하도록 설계한 시스템으로, 도입 후 코드 푸시 지연 시간의 중앙값이 약 80% 줄었다. 오픈AI가 주고받는 깃 데이터는 하루 약 1페타바이트에 이른다.

오픈AI는 개발자들이 쓰는 깃 작업 흐름을 코딩 에이전트와의 협업에 맞게 개선하겠다고 밝혔고, 에이전트가 첫 브랜치를 만드는 순간부터 배포까지의 표준을 세우겠다는 포부도 내놓았다. 코덱스를 코드 작성에서 저장, 검토, 배포까지 아우르는 통합 플랫폼으로 넓히려는 구상이다.

이 때문에 AI타임스는 전문가들이 이번 거래를 마이크로소프트 깃허브에 대한 도전으로 해석한다고 전했다. 깃허브는 오랫동안 코드 저장과 협업의 중심이었던 서비스다.

## 핵심 포인트

- 오픈AI가 깃 기반 코드 저장 서비스 '코드 스토리지'를 만든 피에르를 인수, 금액은 비공개
- 거래는 규제 승인 후 완료되며, 오픈소스 프로젝트와 기존 서비스는 유지
- 코덱스 앱은 이미 피에르의 트리스, 디프스 라이브러리를 사용 중
- 자체 시스템 판도 도입 후 코드 푸시 지연 시간 중앙값 약 80% 감소
- 전문가들은 이번 인수를 마이크로소프트 깃허브에 대한 도전으로 해석
