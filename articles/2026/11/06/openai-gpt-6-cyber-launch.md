# 오픈AI 'GPT-6 사이버' 출시…공격 성공률 51% 높이고 리눅스 공격 코드 948건 개발

## 상세 요약

오픈AI가 5일(현지시간) 사이버 보안 특화 모델 'GPT-6 사이버'를 공개했다. 9월에 나온 GPT-6 아스트라를 바탕으로 취약점 발견, 공격 코드 개발, 침투 테스트에 맞춰 추가 학습한 모델이다. 실제 공격 능력을 끌어올리는 한편, 승인된 보안 업무를 불필요하게 거절하는 일은 줄였다고 AI타임스는 전했다.

당장은 누구나 쓸 수 없다. 오픈AI의 보안 프로그램 '데이브레이크'에서 공격 코드 개발과 침투 테스트까지 허용되는 최상위 등급인 '레드'의 승인 고객에게 API와 코덱스로 먼저 제공된다. 앞으로 몇 주 안에 승인 고객 전체로 넓히고, 발전소와 수처리 시설 같은 핵심 기반시설 보안 담당자를 위한 전용 접근 그룹도 만들 계획이다.

성과로 내세운 것은 리눅스와 파이어폭스다. AI타임스에 따르면 연구진은 리눅스 커널 취약점 1724건을 재현해 그중 948건에서 실제 작동하는 권한 상승 공격 코드를 만들었다. 같은 조건에서 GPT-5.6 솔이 성공한 166건의 5배가 넘는다. 로이터를 인용한 내용으로는 948건 중 588건이 이전에 알려지지 않은 것이었고, 오픈AI는 중요한 문제 304건을 패치와 함께 리눅스 개발자들에게 전달했다. 파이어폭스에서는 새로운 고위험 취약점 81건을 찾았으며, 기존 취약점 30건의 위험도는 이전 평가보다 높게 판단했다. TechCrunch는 948건을 패치를 준비한 잠재적 문제로 표현해 매체 간 설명에 차이가 있다.

벤치마크 결과는 고르지 않다. 실제 취약점 공격 성공률을 재는 익스플로잇짐에서는 48.5%로 GPT-5.6 사이버의 32.1%를 앞섰고, 제목의 51% 향상은 이 차이를 상대 비율로 환산한 값이다. 소스 코드 없이 웹 애플리케이션 취약점을 찾는 평가도 40.3%로 GPT-6 아스트라의 32.0%보다 높았다. 반면 프런티어사이버에서는 288개 과제 중 90개를 풀어 아스트라의 96개에 못 미쳤다. 외부 평가에서는 이레귤러의 장기 공격 평가 11개 과제를 모두 한 번 이상 해결했고, 코그니션의 자체 평가에서는 기존 최고치 13%를 넘는 23%를 기록했다. 다만 아티피셜 애널리시스 같은 독립 종합 평가는 아직 확인되지 않았다.

오픈AI의 내부 평가에서 이 모델은 GPT-5.6 사이버의 '높음'보다 한 단계 위인 '치명적' 등급을 받았다. GPT-6 아스트라와 같은 등급이다. 승인 범위를 지킨 비율은 99.93%였고, 안전 지침을 더하면 평가 전체에서 범위 안에 머물렀다는 것이 오픈AI의 설명이다. 더버지도 시험 중 범위를 벗어난 비율이 1% 미만이었다고 전했다. 모두 회사 측 수치다.

컨텍스트 창은 105만 토큰, 최대 출력은 12만 8000 토큰이다. API 기본 가격은 100만 토큰당 입력 20달러, 출력 100달러, 캐시 입력 2달러다. 팔로알토 네트웍스, 시스코, 센티넬원이 취약점 분석과 보안 연구에 이 모델을 쓰고 있다.

TechCrunch는 이 정도로 충분한지를 따져 물었다. 오픈AI 연구원 에릭 월리스는 최첨단 컴퓨팅 자원의 상당량을 오픈소스 취약점 발굴과 패치에 "fully pro bono"(전액 무상)로 쓰고 있다고 말했고, 리눅스 작업에는 120만 달러가 들었다. 오픈AI는 전력망이나 수도 시설을 지키는 전문가를 위한 10억 달러 규모 계획도 내놓았다. 반면 안전장치를 제거한 오픈 웨이트 모델을 악의적 행위자가 쓸 수 있고, 이전 모델로 약 5000달러를 들여 여러 취약점을 찾았다는 외부 연구자는 데이브레이크 블루 등급의 성능이 최근 낮아진 것 같다고 말했다. 공격 역량의 확산을 접근 통제만으로 막을 수 있느냐는 질문이 남는다.

## 핵심 포인트

- GPT-6 아스트라 기반 보안 특화 모델로, 데이브레이크 레드 승인 고객에게 먼저 제공
- 리눅스 커널 공격 코드 948건 개발, 파이어폭스 고위험 취약점 81건 발견(오픈AI 측 결과)
- 익스플로잇짐 48.5%로 향상됐지만 프런티어사이버는 범용 모델인 아스트라보다 낮음
- 내부 평가 '치명적' 등급, 승인 범위 준수율 99.93%
- API 가격은 100만 토큰당 입력 20달러, 출력 100달러
