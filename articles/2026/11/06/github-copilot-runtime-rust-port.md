## 상세 요약

깃허브 코파일럿 런타임의 타입스크립트 운영 코드 약 40만~45만 줄이 러스트로 옮겨졌다. 마이크로소프트 수석 엔지니어 스티븐 토브의 발표 영상을 정리한 GeekNews 요약에 담긴 내용이다. 목적은 러스트 도입 자체가 아니라 Node.js와 V8 의존성을 벗어나 여러 제품에 내장할 수 있는 공통 에이전트 하네스를 만드는 것이었다.

언어 선택에서는 러스트와 네이티브 AOT 기반 C#이 최종 후보로 남았다. 성능과 내장 가능성은 비슷했고, 깃허브 내부의 기존 러스트 프로젝트와 개발자 경험이 결정 요인이 됐다. 타입스크립트와 파이썬은 초기에 제외됐고, Go와 자바는 내장 용도에 맞지 않는다고 판단했다.

이식은 개발과 배포를 멈추지 않고 진행됐다. 약 14.5주 동안 메인 브랜치에서 구성 요소를 하나씩 교체했고, 그사이 약 130회 출시했다. napi-rs로 타입스크립트와 러스트를 연결했으며, 상호 호출 시그니처는 최대 2000~3000개까지 늘었다가 0개로 줄었다. 옮긴 타입스크립트 코드는 바로 삭제했다.

규모는 처음 예상보다 커졌다. 초기 추정은 약 15만 줄, 6~8주였지만 이식 중 새 코드가 계속 들어오고 CLI와의 결합도 드러나 약 3배로 늘었다. 작업은 에이전트가 맡고 여러 모델이 코드 리뷰를 했으며, 엔드투엔드 테스트가 주된 안전장치였다. 비용은 약 1360억 토큰으로, 공개 정가 기준 약 12만 달러다.

요약에는 메모리 10배, 지연 5~6배 개선이라는 수치도 나오지만 확정된 벤치마크가 아니라 예시로 제시됐다. 회귀 버그의 약 3분의 2는 사전 출시 전에 잡혔다. 발표 영상 본문은 직접 확인하지 못했다.
