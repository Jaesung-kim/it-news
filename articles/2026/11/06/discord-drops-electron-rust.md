# 디스코드, 일렉트론 버리고 러스트로 전면 전환…CTO 공개 이미지 RAM 사용량 290MB

## 상세 요약

디스코드가 데스크톱 앱에서 일렉트론을 걷어내고 앱 전체를 러스트로 옮기고 있다. 이 소식은 더버지 보도를 정리한 GeekNews 요약에 담겼고, 해커뉴스에서도 300점 넘는 관심을 모았다.

가장 눈에 띄는 수치는 메모리 사용량이다. 최고기술책임자(CTO)가 공개한 윈도우 클라이언트 이미지에서 RAM 사용량은 290MB였다. 현재 앱은 서버 몇 곳에만 참여해도 1GB 이상에 쉽게 이른다는 것이 비교 기준이다.

변화는 모바일로도 이어진다. 디스코드는 모바일에서 리액트 네이티브를 제거하되 네이티브 UI는 유지하고, 러스트를 통해 데스크톱과 모바일의 앱 코드를 공유할 계획이다.

디스코드에 러스트가 낯선 기술은 아니다. 회사는 2018년부터 러스트를 도입해 인프라와 음성 기술 상당 부분, 기존 클라이언트 일부에 이미 사용해 왔다. 다만 전체 전환 시점은 정해지지 않아, 공개된 290MB 수치가 일반 이용자 환경에서도 재현될지는 출시 뒤에 확인할 수 있다.

## 핵심 포인트

- 디스코드가 데스크톱 앱에서 일렉트론을 제거하고 러스트로 전면 전환 중
- CTO 공개 이미지 기준 윈도우 클라이언트 RAM 사용량은 290MB
- 현재 앱은 서버 몇 곳만 참여해도 1GB 이상에 쉽게 도달
- 모바일에서도 리액트 네이티브를 없애고 러스트로 코드 공유 계획
- 전체 전환 시점은 미정
