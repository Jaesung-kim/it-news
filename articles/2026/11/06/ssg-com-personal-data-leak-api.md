# SSG닷컴, API 취약점으로 개인정보 유출…고객 성명·내부 고객번호 조회돼

## 상세 요약

SSG닷컴에서 일부 고객의 개인정보가 외부로 유출됐다. 회사는 6일 대상 고객에게 이 사실을 개별 안내했다. 유출된 정보는 대부분 고객 성명과 내부 식별용 고객번호다.

원인은 응용 프로그램 인터페이스(API) 취약점이다. 외부에서 이 취약점을 이용해 불법으로 접근하면서 비인가자가 개인정보를 조회할 수 있었던 것으로 설명됐다.

회사는 4일 유출 사실을 파악하고 추가 보안 조치를 진행했다. 신고는 한국인터넷진흥원(KISA)에 5일, 개인정보보호위원회에 6일 이뤄졌다.

SSG닷컴 관계자는 "이번 유출에 따른 추가 피해는 확인되지 않았다"고 말했다. 회사는 고객 피해 예방과 재발 방지에 최선을 다하겠다고 밝혔다. 유출된 고객 수는 공개되지 않았다.

## 핵심 포인트

- API 취약점을 이용한 외부 접근으로 일부 고객 개인정보가 조회됨
- 유출 항목은 대부분 고객 성명과 내부 식별용 고객번호
- 4일 인지, KISA 5일·개인정보위 6일 신고, 6일 고객 개별 안내
- 회사는 추가 피해가 확인되지 않았다고 설명했고, 유출 규모는 미공개
