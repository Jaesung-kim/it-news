# 알리바바 '큐원4 맥스' 정식 출시…활성 매개변수 25% 줄이고 작업당 비용 67% 절감

- 분야: AI 뉴스
- 출처: AI타임스 (알리바바 큐원팀 공식 블로그 인용)
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217466
- 발행일: 2026-11-16

## 상세 요약

알리바바가 차세대 AI 모델 '큐원4 맥스(Qwen4-Max)'를 16일(현지시간) 정식 출시했다. 11일 프리뷰를 시작한 지 5일 만으로, 당시 공개하지 않았던 아키텍처와 벤치마크, API 가격을 큐원팀 공식 블로그를 통해 밝혔다.

모델은 전문가 혼합(MoE) 구조로 총 매개변수는 전작 큐원3.8 맥스와 같은 약 2조4000억개다. 대신 추론 때 실제로 쓰는 활성 매개변수를 950억개에서 710억개로 25% 줄였다. 이와 별도로 3280억개 규모의 N-그램 임베딩 매개변수를 두었고, 게이티드 델타넷(Gated DeltaNet), 큐원 희소 어텐션 등의 구성 요소를 적용했다.

성능은 오르고 비용은 내렸다. 아티피셜 애널리시스의 지능 지수에서 큐원4 맥스는 43점으로 전작(34점)보다 올랐고, 작업당 평균 비용은 10.02달러에서 3.27달러로 약 67% 줄었다. 문샷AI의 키미 K3.1 프로(46점, 3.68달러)와 비교하면 점수는 낮지만 더 저렴하다. 소프트웨어 개발 평가인 딥SWE 1.1에서는 75.7점으로 앤트로픽 오퍼스 5.5(74.2점)를 앞섰으나, 터미널벤치 4.0에서는 48.5%로 키미 K3.1(67.2%)에 크게 뒤졌다.

알리바바 자체 전문 업무 평가 '워크360'에서는 52.69점으로 전작(47.74점)보다 높아졌고 작업당 비용은 4.43달러에서 1.67달러로 약 62% 낮아졌다. 토큰 사용량도 워크360에서 24~35%, 터미널벤치 4.0에서 약 48~49% 줄었다. 에이전트 아레나 순위는 39위에서 14위로 올랐다.

알리바바는 활용 사례로 자동차 부품 제조의 수작업 프로그래밍 시간을 약 475분에서 24분으로 줄인 사례, 에이전트가 48시간 동안 설계·합성·실험·분석을 반복해 반도체 냉각 소재 후보를 찾아낸 사례 등을 소개했다. 안전 측면에서는 코딩 학습에 보안 검사를 넣고 사이버 공격에 쓰일 수 있는 데이터를 걸러냈다고 밝혔다.

API 가격은 입력 100만 토큰당 1.5달러, 출력 100만 토큰당 4.5달러로 이전보다 약 25% 내렸고, 캐시 입력은 0.075달러로 70% 저렴해졌다. 최대 100만 토큰 컨텍스트와 텍스트·이미지·영상 입력을 지원하며, 프리뷰 때 구독자 전용이던 API를 큐원 클라우드에서 종량제로 쓸 수 있게 했다. 모델 가중치는 공개하지 않았고, 소형 큐원4 모델은 오픈웨이트로 내놓겠다고 했지만 규모와 시점은 밝히지 않았다.

## 핵심 포인트

- 프리뷰 5일 만에 정식 출시, 총 2조4000억 매개변수 MoE에 활성 매개변수는 710억개로 25% 감축
- AA 지능 지수 43점(전작 34점), 작업당 비용 10.02달러→3.27달러로 약 67% 절감
- 딥SWE 1.1에서 오퍼스 5.5 앞섰지만 터미널벤치 4.0에서는 키미 K3.1에 크게 뒤짐
- API 가격 입력 1.5달러·출력 4.5달러(100만 토큰당)로 인하, 종량제 도입
- 가중치 비공개, 소형 모델만 오픈웨이트 예정
