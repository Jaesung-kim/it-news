# 'Unkernel' 공개…실제 리눅스 커널을 웹어셈블리로 컴파일해 브라우저 탭에서 데비안·알파인 부팅

## 상세 요약

리눅스 커널을 웹어셈블리(WebAssembly)로 컴파일해 브라우저 탭 안에서 돌리는 프로젝트 'Unkernel'이 공개됐다. 에뮬레이터로 다른 CPU를 흉내 내는 방식이 아니라 실제 리눅스 커널을 웹어셈블리 대상으로 빌드한 것이 특징이며, 수정하지 않은 aarch64 사용자 공간 프로그램을 그대로 실행할 수 있다.

부팅할 루트 파일 시스템으로는 데비안(기본값), 알파인, 기본 셸을 고를 수 있다. 파일 시스템에서 바꾼 내용은 배포판별로 브라우저 저장소에 남아 다음에 다시 열어도 유지된다.

여러 CPU를 선택하면 SMP 커널로 부팅하며 CPU마다 웹 워커(Web Worker)를 하나씩 쓴다. 자주 실행되는 게스트 코드는 JIT 컴파일러가 웹어셈블리로 바꿔 속도를 높인다.

네트워크는 Wisp 프로토콜로 게스트에 인터넷 연결을 제공한다. 게스트 안에서 띄운 웹 서버를 브라우저 창이나 별도 탭으로 열어 볼 수도 있다. 그래픽은 virgl과 virtio-gpu를 거쳐 WebGL2로 처리하고, 소리는 ALSA와 /dev/dsp를 지원한다. 일시 중단과 재개 기능도 갖췄다.

GeekNews에 소개된 해커뉴스 반응으로는 Unkernel 안에서 크로미엄을 다시 실행하는 중첩 실행에 성공했다는 이야기와 아이패드에서 동작했다는 사례 등이 공유됐다. 프로젝트 웹사이트는 확인 시점에 앱이 시작되지 않아, 이 요약은 GeekNews 소개 내용을 기준으로 했다.

## 핵심 포인트

- 실제 리눅스 커널을 웹어셈블리로 컴파일해 브라우저 탭에서 실행한다
- 수정하지 않은 aarch64 사용자 공간을 지원하며 데비안·알파인으로 부팅할 수 있다
- CPU마다 웹 워커를 쓰는 SMP 부팅과 JIT 컴파일을 지원한다
- Wisp 네트워크, WebGL2 그래픽, ALSA 사운드, 일시 중단·재개 기능을 갖췄다
