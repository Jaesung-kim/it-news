# 사카나 AI, 30B 추론 모델 '나마즈 스몰' 공개…25개 벤치마크 평균 60.1점으로 4배 큰 120B 모델(56.2) 앞서

- 분야: AI 뉴스
- 출처: AI타임스(사카나 AI 공식 블로그 인용)
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217892
- 발행일: 2026-11-28

## 상세 요약

일본 사카나 AI가 11월 25일 공식 블로그를 통해 소형 추론 모델 '사카나 나마즈 스몰(Sakana Namazu Small)'을 공개했다. 웹 검색과 장문서 이해에 집중한 모델로, 기업이 외부 클라우드에 의존하지 않고 자체 서버에서 돌릴 수 있도록 만들었다.

구조는 총 매개변수 300억개, 추론 시 활성 매개변수 30억개인 전문가 혼합(MoE) 모델이다. 엔비디아의 '네모트론 3 나노(Nemotron 3 Nano)' 사전 학습 모델을 기반으로, 사카나 AI가 추가 사전 학습과 사후 학습을 독자적으로 진행했다. 기존 '사카나 나마즈' 개발에서 쌓은 학습 기술에 새 기법을 더했고, 일본 경제산업성과 NEDO의 국산 생성 AI 지원 사업 '제니악(GENIAC)' 성과를 활용했다.

겨냥한 작업은 두 가지다. 하나는 기업 내부 문서와 보고서에서 답의 근거를 찾아내는 문서 분석이고, 다른 하나는 여러 웹사이트를 반복 검색해 정보를 모아 종합하는 심층 조사다.

사카나 AI의 자체 평가에서 25개 벤치마크 평균은 60.1점으로, 매개변수가 4배 많은 '네모트론 3 슈퍼'(120B-A12B)의 56.2점과 같은 규모의 '나노'(30B-A3B) 50.2점을 모두 넘었다. 25개 항목 중 13개에서 슈퍼를, 22개에서 나노를 앞섰다.

개별 지표 격차는 더 컸다. 웹 검색 기반 추론을 보는 브라우즈컴프에서 73.5점을 받아 슈퍼(36.1점)의 두 배를 넘었고, 심층 정보 검색인 딥서치QA는 84.3점(슈퍼 65.4, 나노 70.7)이었다. 일본어 장문서 평가 LLM-jp 롱벤치는 86점(슈퍼 60), 문서 내 근거 인용을 보는 롱벤치-사이트는 80.2점(슈퍼 68.3)이었다.

약점도 분명했다. 외부 검색 없이 모델 내부 지식만으로 답하는 심플QA 베리파이드에서는 6.8점에 그쳐 나노(9.1)와 슈퍼(18.1)보다 낮았다. 사카나 AI는 모델 자체의 지식 역량을 보완하겠다고 밝혔다.

모델 가중치와 라이선스, 가격은 아직 공개되지 않았다. 기업이 자체 인프라에서 운영하는 온프레미스 공급을 추진 중이며, 구체적인 계획은 12월에 발표할 예정이다. 제시된 수치는 모두 사카나 AI의 자체 평가로, 독립 검증 결과는 아직 없다.

## 핵심 포인트

- 총 300억·활성 30억 매개변수 MoE 추론 모델로, 네모트론 3 나노를 기반으로 추가 학습했다.
- 25개 벤치마크 평균 60.1점으로 4배 큰 120B 모델(56.2)을 앞섰다.
- 브라우즈컴프 73.5점으로 120B 모델(36.1)의 두 배를 넘었다.
- 내부 지식만 쓰는 심플QA 베리파이드는 6.8점으로 비교 모델보다 낮았다.
- 가중치·가격은 미공개이며 온프레미스 공급 계획을 12월에 발표한다.
