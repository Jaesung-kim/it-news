# 바이트댄스, 에이전트 강화학습 프레임워크 '라미나' 오픈소스 공개…SWE-bench 46.6%→52.2%, GPU 시간 5085→1843시간

- 분야: AI 뉴스
- 출처: AI타임스(바이트댄스 시드 깃허브·arXiv 논문 인용)
- 원문 링크: https://www.aitimes.com/news/articleView.html?idxno=217894
- 발행일: 2026-11-28

## 상세 요약

바이트댄스의 AI 연구 조직 시드(Seed)와 홍콩대학교 공동 연구진이 11월 24일 AI 에이전트 강화학습 프레임워크 '라미나(Laminar)'를 깃허브에 오픈소스로 공개했다. 지난해 10월 arXiv 논문(2510.12633)으로 먼저 소개한 기술로, 이번에 소스 코드와 코딩 에이전트 학습 실험 결과를 함께 내놨다. 라이선스는 상업적 이용이 가능한 아파치 2.0이다.

문제의 출발점은 GPU 유휴 시간이다. 에이전트가 수행하는 작업은 완료까지 걸리는 시간이 제각각이라, 먼저 끝난 GPU가 느린 작업을 기다리며 놀게 된다. 장시간 작업을 다루는 에이전트일수록 이 낭비가 커진다.

라미나는 학습 데이터 생성, 모델 학습, 새 가중치 전달을 각각 따로 진행하는 비동기 구조를 쓴다. 기존 비동기 시스템도 데이터 생성과 학습을 분리했지만 새 가중치를 적용할 때 모든 추론 서버를 한꺼번에 업데이트해야 했다. 라미나는 학습 쪽이 새 가중치를 별도 중계 시스템에 올려두고 각 추론 서버가 필요한 시점에 가져가게 했다. 하나의 작업은 같은 모델 버전으로 끝내 데이터 일관성을 지킨다. 오래 걸리는 작업을 소수 GPU에 모으는 '리팩(Repack)' 기능도 넣었고, 일부 추론 서버에 장애가 나도 전체 학습을 멈추지 않고 해당 부분만 복구할 수 있다.

실험은 알리바바의 '큐원3-코더-30B-A3B-인스트럭트'로 진행했고, 소프트웨어 문제 해결을 재는 SWE-bench Verified로 평가했다. 강화학습 전 46.6%였던 해결률이 라미나 적용 뒤 52.2%로 올라, 기존 학습 방식의 최고치인 51.4%를 넘었다.

자원 절감 폭이 더 눈에 띈다. 학습 샘플은 7만6400개에서 5만1200개로 33% 줄었고, GPU 사용 시간은 5085시간에서 1843시간으로 64% 줄었다. 같은 51.4% 해결률을 기준으로 맞추면 샘플은 46%, GPU 시간은 71% 감소했다. 다만 기존 시스템은 H100 GPU 64개, 라미나는 H800 GPU 64개를 썼기 때문에 실험 조건이 완전히 같지는 않다.

논문에서는 GPU 1024개 규모 실험에서 기존 강화학습 시스템 대비 최대 5.48배의 학습 처리량을 기록했다고 밝혔다. 연구진은 학습과 평가를 재현할 수 있는 실행 방법도 함께 공개했다.

## 핵심 포인트

- 바이트댄스 시드와 홍콩대가 에이전트 강화학습 프레임워크 라미나를 아파치 2.0으로 공개했다.
- 새 가중치를 중계 시스템에 두고 추론 서버가 필요할 때 가져가는 비동기 구조다.
- SWE-bench Verified 해결률이 46.6%에서 52.2%로 올라 기존 최고치 51.4%를 넘었다.
- GPU 사용 시간은 5085시간에서 1843시간으로 64%, 학습 샘플은 33% 줄었다.
- 비교 실험에 H100과 H800이 섞여 조건이 동일하지는 않다.
