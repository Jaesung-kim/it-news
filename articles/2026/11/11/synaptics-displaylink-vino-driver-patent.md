# 시냅틱스 특허 경고에 리눅스용 DisplayLink 오픈소스 드라이버 '비노' 개발 중단…주당 2만 5000달러 청구 위협

- 분야: IT 뉴스
- 출처: LWN.net, Hacker News, GeekNews
- 원문: https://lwn.net/SubscriberLink/1102549/acbc92e00cee3a3f/
- 발행일: 2026-11-10

## 상세 요약

DisplayLink 칩셋을 쓰는 델 도킹 스테이션 사용자 마이크 로시언은 제조사가 제공하는 리눅스용 소프트웨어(DLM)가 불안정하다는 이유로 직접 드라이버를 만들기 시작했다. LLM의 도움을 받아 Rust로 작성한 DRM/KMS 드라이버 '비노(Vino)'로, 2026년 6월 17일 dri-devel 메일링 리스트에 RFC로 올렸다. DisplayLink는 2022년 시냅틱스에 인수됐으며, DLM은 x86 전용 바이너리로만 배포되고 오픈소스 부분은 커널 모듈 EVDI뿐이다.

비노는 세 번째 패치 버전에서 제조사 소프트웨어 없이 3세대에 걸친 DL3 도킹 스테이션을 구동할 수 있는 수준에 이르렀다. 초기 버전은 화면 하나도 켜지 못했지만, 도킹 스테이션의 제어 채널과 통신하는 문제를 풀어 가며 진전을 이뤘다.

시냅틱스의 대응은 7월부터 시작됐다. 시냅틱스 측은 DisplayLink의 프로토콜과 코덱이 영국을 포함해 특허로 보호되며, 클린룸 방식으로 구현해도 특허 침해를 피할 수 없다고 경고했다. 8월 17일에는 특허 125건을 나열한 중단 요구서를 보냈는데, 개발 중단, 커널 관리자와 배포판에 낸 제출물 철회, 게시 위치 전부 공개 등 8가지를 요구했다. 다만 특허를 비노 코드와 대응시킨 자료는 없었다.

로시언이 특허와 코드의 대응 관계(클레임 차트)를 요구하자, 시냅틱스는 10월 5일 2010년 출원된 영국 특허 2건의 클레임 차트를 보냈다. 요구에 응하지 않으면 2만 5000달러를 청구하고 매주 같은 금액을 더하겠다고 통보했고, 기한은 10월 18일로 한 차례 연장된 뒤 더는 미루지 않겠다고 못 박았다.

시냅틱스는 리눅스 특허 상호 보호 단체인 OIN의 회원사이지만, OIN은 코덱이 자체 '리눅스 시스템 정의'에 포함되지 않는다는 이유로 이번 사안이 보호 대상이 아니라고 결론 내렸다. 결국 로시언은 GitHub 저장소를 내리고 커널 제출도 멈췄다. 그는 "시냅틱스를 상대로 스스로를 방어할 여력이 없다"며 비노를 당분간 개인 환경에만 두겠다고 밝혔다.

커널 쪽에서도 실질적인 도움은 없었다. 비노 v3는 사람의 검토 없이 자동 리뷰만 받았다. 이번 사례는 개인 개발자가 독점 하드웨어의 오픈소스 드라이버를 만들 때 특허 위협 앞에서 얼마나 취약한지를 보여 준다.

## 핵심 포인트

- 리눅스용 Rust 기반 DisplayLink 드라이버 '비노'가 시냅틱스의 특허 경고로 공개 개발을 멈췄다
- 시냅틱스는 특허 125건을 나열한 중단 요구서를 보냈고, 이후 영국 특허 2건의 클레임 차트를 제시했다
- 불응 시 2만 5000달러에 매주 같은 금액을 더해 청구하겠다고 통보했다
- OIN은 코덱이 보호 범위 밖이라며 개발자를 보호하지 않았다
- 개발자는 GitHub 저장소를 내리고 커널 제출을 중단했다
