# 구글 딥마인드 '알파프루프 코드', 시그널 암호 라이브러리 보안 수학적으로 증명…4주간 린 코드 650만 줄 작성

- 분야: AI 뉴스
- 출처: AI타임스, Google DeepMind
- 원문: https://www.aitimes.com/news/articleView.html?idxno=217275
- 발행일: 2026-11-10

## 상세 요약

구글 딥마인드가 10일(현지시간) 공식 블로그에서 여러 AI 에이전트를 묶은 정형 검증 시스템 '알파프루프 코드(AlphaProof Code)'를 공개했다. 첫 적용 대상으로 메신저 시그널의 핵심 암호화 라이브러리 '립시그널(libsignal)'을 골라, 실제 기기에서 돌아가는 코드가 핵심 보안 조건을 충족한다는 사실을 수학적으로 증명했다고 밝혔다.

작업 흐름은 이렇다. 먼저 연구진과 AI가 지켜야 할 보안 조건을 수학적 명세로 쓰고, 사람이 이를 검토해 승인한다. 이어 '제미나이 4 카본' 기반 에이전트들이 증명 언어 린(Lean)으로 증명을 작성하고, 린의 검증기가 그 증명을 기계적으로 확인한다. 논리에 빈틈이 있으면 최종 검증을 통과할 수 없는 구조다.

에이전트들은 4주 동안 650만 줄이 넘는 린 증명 코드를 썼다. 사람이 따로 들여다봐야 할 부분은 전체 코드베이스의 약 1%로 줄었다. 딥마인드는 예전 같으면 전문가 팀이 수년 걸렸을 작업이라고 설명했다.

AI타임스에 따르면 검증 대상은 시그널 종단간 암호화의 'PQXDH 핸드셰이크'와 '트리플 래칫'이다. 메시지 기밀성과 인증, 순방향 비밀성, 사후 침해 보안 같은 속성이 컴파일된 실제 코드에서 성립함을 보였고, 양자컴퓨터 공격을 가정한 일부 조건은 별도 수학 모델로 검증했다. 탐지력도 시험했다. 과거에 고쳐진 시그널 버그 2건을 코드에 다시 넣자, 두 경우 모두 보안 조건을 만족하지 못한다는 사실을 증명해 냈다.

시그널의 에런 크렛 최고기술책임자(CTO)는 "실제 코드를 유효한 린 정리로 옮기는 데 AI 에이전트를 쓴 것은 큰 돌파구"라고 평가했다. 딥마인드는 명세와 증명 자료를 깃허브에 오픈소스로 공개했고, 의료기기 소프트웨어나 전력망 같은 분야로의 적용도 기대한다고 밝혔다.

한계도 있다. 검증 범위는 특정 실행 환경에서 컴파일한 1:1 메시징 암호화 코드로 한정되며, 그룹 메시징과 여러 기기 간 상태는 빠졌다. 일부 암호 기본 요소와 검증 도구 자체의 정확성은 가정으로 두었기 때문에, 시그널 앱 전체의 안전을 보장하는 결과는 아니다. 구글은 6일 AI로 RSA 암호의 약점을 찾은 연구에 이어, 암호 분석에서 실제 소프트웨어 검증까지 AI 활용 범위를 넓히고 있다.

## 핵심 포인트

- 다중 AI 에이전트 정형 검증 시스템 '알파프루프 코드'로 립시그널 보안 속성 증명
- 제미나이 4 카본 기반 에이전트가 4주간 린 증명 코드 650만 줄 이상 작성
- 사람이 검토할 영역은 코드베이스의 약 1%로 축소
- 과거 수정된 버그 2건을 다시 넣자 모두 보안 조건 위반으로 판정
- 1:1 메시징 코드에 한정, 그룹 메시징·다중 기기는 검증 범위 밖

> 배경(편집자 설명): 딥마인드 공식 발표는 https://deepmind.google/blog/introducing-alphaproof-code/ 에서 볼 수 있다.
